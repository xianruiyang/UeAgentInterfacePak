  - 进入中段后开始持续下降
  - 到生命周期末端降到接近 `0`
- 下方可见 `Scale Curve = 1.0`
- 左侧预览窗口能看到一团蓝紫色粒子残留，说明该曲线正用于控制这层粒子的可见度退场

这张图可以可靠转写为：这一层粒子不是一出生就快速变暗，而是先在前段保持可见，随后沿 `NormalizedAge` 平滑衰减到完全透明。复现时如果粒子一闪而过或突然断掉，优先检查 `Alpha` 曲线是否像图中这样做成“前稳后降”的走势，而不是直接用线性从 1 到 0 的短促衰减。

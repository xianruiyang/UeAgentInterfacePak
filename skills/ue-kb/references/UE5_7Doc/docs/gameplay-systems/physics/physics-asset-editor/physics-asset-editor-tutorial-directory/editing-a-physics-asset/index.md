# 编辑物理资产

> 路径：虚幻引擎5.7文档 / Gameplay系统 / 物理 / 物理资产编辑器 / 物理资产编辑器教程 / 编辑物理资产

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/editing-a-physics-asset-in-unreal-engine

以下步骤说明如何在 **物理资产编辑器** 中打开 **物理资产** 进行编辑。

## 步骤

1. 在 **内容侧滑菜单（Content Drawer）** 中找到 **物理资产**。

   ![Find the Physics Asset in the Content Drawer](../../../../../../assets/images/07/074277c4fa7a204c6102840cf15b8ce6dd19b89d538132b1782e0c8f192f076a.jpg)
2. **双击** 将其在物理资产编辑器中打开。

   ![Double-click it to open it in the Physics Asset Editor](../../../../../../assets/images/f0/f02c48776d916310300fe32fa85c4c25ed2bb6aed50b175a8fcf9e67a41ddbf9.jpg)

## 结果

物理资产成功打开，可以在物理资产编辑器中进一步编辑了。

# Niagara轻量级发射器

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/niagara-lightweight-emitters

Niagara **轻量级发射器** 也被称为 **无状态发射器**， 是为了在模拟期间尽可能少使用（以及在某些情况彻底不使用）tick而进行的优化。

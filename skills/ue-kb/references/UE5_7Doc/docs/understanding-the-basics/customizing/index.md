# 自定义虚幻引擎

> 路径：虚幻引擎5.7文档 / 理解基础知识 / 自定义虚幻引擎

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/customizing-unreal-engine

**虚幻引擎5** （UE5）在操作体验的自定义方面提供了极大的灵活性。你可以使用UE5的内置工具来创建和保存自定义布局，改变界面配色方案，编辑快捷键，添加或删除各种保存在独立插件中的功能。

请参考下述页面，详细了解UE5中的各种自定义选项。

- [使用插件](../foundational-knowledge-in/working-with-plugins/index.md) - 在虚幻引擎中安装、启用和禁用插件

- [自定义按键快捷键](../foundational-knowledge-in/customizing-keyboard-shortcuts/index.md) - 介绍如何调整虚幻引擎中常用命令的快捷键，创建新的快捷键以便适应你的使用习惯。

- [编辑器偏好设置](../foundational-knowledge-in/unreal-editor-preferences/index.md) - 用于配置控件、视口、源码管理等通用编辑器行为的选项。

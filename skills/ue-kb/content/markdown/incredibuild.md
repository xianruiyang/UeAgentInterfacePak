### 概览

*由 Epic Games 员工撰写的文章* 如果您经常在多个流中工作，那么为多个构建设置 Incredibuild 确实非常有用，这样您就可以一次构建多个项目： - 右键单击 Windows 应用程序托盘上的 Incredibuild > Agent 设置 - 启动器 > 多个构建 > 设置为超过 1 如果您厌倦了构建时计算机锁定，请更改 CPU 利用率的设置： - Agent > CPU 利用率 > 从下拉列表中选择“用户定义”，然后限制核心数量请参阅[知识库](https://forums.unrealengine.com/docs?category=)了解更多信息。

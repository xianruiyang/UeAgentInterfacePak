# 虚拟堪景

> 路径：虚幻引擎5.7文档 / 构建虚拟世界 / 虚拟堪景

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/virtual-scouting-in-unreal-engine

## 概述

电影人能利用 **虚拟堪景工具** 在虚拟制片环境中导航和交互。导演和摄影指导（DOP）可轻松找到拍摄位置、设计镜头、设置场景布局，并获得拍摄位置的准确展示。美术师和布景师可在虚拟现实（VR）中一边体验拍摄位置，一边搭建布景，使用测量和交互工具检查距离并修改场景。你也可在虚拟场景中采集图像，帮助制片团队追踪在VR会话中做出的决定。你还可以直接利用蓝图自定义控制器和设置项，无需使用C++，也无需重新编译引擎。

虚幻引擎的虚拟堪景工具基于XR创意框架设计，该框架为开发者提供了一套[工具包](customizing-virtual-scouting/index.md)，可使用蓝图创建基于头显设备的增强现实（XR）工具。

> [!NOTE]
> 未来的引擎版本将逐步减少使用并最终弃用[旧版虚拟堪景工具](virtual-scouting-legacy-tools/index.md)。推荐用户使用新版虚拟堪景工具。未来的引擎版本将彻底废弃未使用的VREditor代码和模块。

## 先决条件

新版工具要求使用虚幻引擎5.4或更高版本，需要使用Windows计算机，硬件配置必须支持VR，以及任意一种下列头显设备：

- Meta Quest 2
- Meta Quest 3
- Meta Quest Pro
- Oculus Rift S
- Valve Index

## 设置

如果你满足这些先决条件且希望开始使用虚拟堪景，请参阅[设置虚拟堪景](setting-up-virtual-scouting/index.md)文档。

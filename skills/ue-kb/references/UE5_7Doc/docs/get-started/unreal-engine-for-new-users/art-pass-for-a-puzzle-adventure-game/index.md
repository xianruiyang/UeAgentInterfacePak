# 解谜冒险游戏美术创作指南

> 路径：虚幻引擎5.7文档 / 入门指南 / 虚幻引擎新用户指南 / 解谜冒险游戏美术创作指南

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/art-pass-for-a-puzzle-adventure-game

虚幻引擎包含一套完整的工具，旨在帮助设计师和美术师以直观且富有创意的方式将项目变为现实。 无论你是美术师、设计师还是技术美术师，都可以使用这些工具，直接在编辑器中创建高度细致且完整呈现的游戏世界，并打造实时互动体验。

本系列指南将引导你使用编辑器内的工作流程与工具，为你所构建的游戏世界进行美术创作。 游戏中的美术选择具有主观性。 本系列内容可能会涉及你通过《设计师专题教程》掌握的知识，当然，你也可以从零开始学习本系列。 无论是哪种情况，你都将通过实际的例子来学习基础工作流程，以及如何将一些美术工具与游戏玩法相结合。

### 美术师专题教程概览

本系列通过贴近真实游戏和玩法的示例，带你一步步入门，了解面向美术师的基础工作流程。 这些内容将帮助你更好地理解虚幻引擎各系统与工具如何协同运作，让你的游戏真正“活”起来。

通过本系列，你将学会：

- 导入用于构建此游戏材质与音频的内容。

- 使用局部光源营造氛围，同时利用光源的内置属性突出设计元素。
- 创建材质和材质实例，利用父/子项关系来设计和编辑场景几何体的表面属性。
- 通过一个互动玩法示例，深入理解材质实例化的应用。
- 以非破坏性的方式添加后期处理，设定场景的整体视觉风格与氛围。
- 结合后期处理与材质，创建游戏过程中的伤害效果。
- 使用内置MetaSounds合成器创作原创音乐，以此作为环境背景音乐。
- 将由玩法驱动的音效与材质相结合，使角色在不同的表面行走时播放不同的声音。
- 使用内置视觉特效系统Niagara创建视觉特效。

### 开始之前

本系列是虚幻引擎初学者课程中的第三个系列，旨在帮助新用户入门。 虽然你无需完成前两个课程也能学习本系列，但如果你已熟悉[《编写第一人称冒险游戏》](../code-a-firstperson-adventure-game/index.md)和[《设计解谜冒险游戏》](../design-a-puzzle-adventure-game/index.md)的内容，你将获得更好的学习效果。 这些课程的内容有助于巩固你通过本系列掌握的知识。

本课程展示的关卡承接了《设计解谜冒险游戏》的内容。 虽然在本课程的某些部分，你不必使用该项目的关卡和设计也能学习，但有些步骤的确需要基于该项目才能完成。

你将在下面找到该项目的两种版本：

- 一个“干净”版本，承接了《设计解谜冒险游戏》中的内容。
- 一个完成版本，包含本课程中所讲解的概念与工作流程示例。

> [!NOTE]
> 对于任何项目而言，美术指导本身就是一种设计选择。 虽然本系列指南会演示许多内容，但你也可以尝试发挥创意，做出属于自己的选择。 无论是学习处理光照、后期处理、部分材质开发内容，还是声音的过程中，你都可以大胆进行尝试，探索不一样的选择。 在很多情况下，即使你的选择与本课程示例不同，也不会影响或阻止你完成整个课程。

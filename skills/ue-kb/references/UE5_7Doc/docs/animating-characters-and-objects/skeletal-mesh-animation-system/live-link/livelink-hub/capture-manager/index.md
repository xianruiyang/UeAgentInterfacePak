# 捕获管理器

> 路径：虚幻引擎5.7文档 / 为角色和对象制作动画 / 骨架网格体动画系统 / Live Link / LiveLink Hub / 捕获管理器

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/capture-manager

[Live Link Hub](../index.md)中的**捕获管理器（Capture Manager）**用于摄取由各种设备所捕获的素材，包括音频、单目和立体视频，以及使用**Live Link Face**应用程序的移动设备所捕获的素材等。 这些素材被称为镜头试拍（Take）。

> [!NOTE]
> Live Link Hub中的**捕获管理器布局（Capture Manager Layout）**取代了**虚幻引擎**中的捕获管理器工具。 未来的虚幻引擎版本将移除原本的捕获管理器工具。

- [捕获管理器设备](capture-manager-devices/index.md) - 了解如何使用捕获管理器中可用的设备。
- [配置捕获管理器](configuring-capture-manager/index.md) - Live Link Hub和虚幻引擎中都可以配置捕获管理器。

下面的参考页面列出了虚幻引擎中所有默认 **材质功能** 的信息和使用示例。它们按照[材质编辑器](https://dev.epicgames.com/documentation/404)面板中的类别排列。


- [枢轴点绘制器工具1.0材质函数](../../../artists-tools-and-workflows-b5279c20/pivot-painter-tool/pivot-painter-tool-1.0/painter-tool-1.0-material-functions/index.md)

- [枢轴绘制器工具2.0材质函数](../../../artists-tools-and-workflows-b5279c20/pivot-painter-tool/pivot-painter-tool-2.0/painter-tool-2.0-material-functions/index.md) - 在虚幻引擎着色器网络中与枢轴绘制器2 MAXScript配合使用的虚幻引擎材质函数。

- [混合材质函数](blend-material-functions/index.md) - 这些函数用于将一种颜色与另一颜色混合，这类似于流行图像编辑应用程序中的混合模式。

- [渐变材质函数](gradient-material-functions/index.md) - 以程序方式生成要添加至材质的渐变，从而消除对纹理的需求并节省内存。

- [图像调整材质函数](../unreal-engine-material-fun-26349ac1/image-adjustment-material-functions/index.md) - 这些函数用来对现有的图像纹理进行调整，例如改变对比度或色调。

- [数学材质函数](math-material-functions/index.md) - 这些材质函数进行预先配置的数学运算，例如计算 π 以及将矢量分量相加等等。

- [杂项材质函数](misc-material-functions/index.md) - 未归入现有类别的杂项材质函数。

- [不透明度材质函数](opacity-material-functions/index.md) - 这些函数用于处理材质网络中的不透明值。

- [粒子材质函数](particles-material-functions/index.md) - 这些专用函数用来帮助设置复杂粒子网络的外观。

- [程序化材质函数](../unreal-engine-material-function-26349ac1/procedurals-material-functions/index.md) - 以程序方式生成的纹理和操作，例如根据现有的高度贴图来创建法线贴图。

- [反射材质函数](../unreal-engine-material-function-26349ac1/reflections-material-functions/index.md) - 这些函数帮助计算各种反射类型的值。

- [纹理材质函数](texturing-material-functions/index.md) - 各种用于帮助处理纹理的函数，例如重新投射 UV 以及裁切等等。

- [向量运算材质函数](vector-ops-material-functions/index.md) - 这些函数用来处理向量数学运算，例如计算菲涅耳效果。

- [世界位置偏移函数](../unreal-engine-materia-26349ac1/world-position-offset-material-functions/index.md) - 这些函数使用全局位置偏移来处理顶点操作。

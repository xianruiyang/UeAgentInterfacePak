### 问题 ：

那么让我们谈谈我们面临的问题。当我们尝试运行从 UE5 导出的“game.exe”时，它会显示此错误，并让我们在重新打开游戏时一次又一次地卸载并安装 MS Visual C++ Redistributable。当我们点击“卸载”然后再次打开时，它会提示Visual C++的安装窗口，安装C++后，游戏运行正常，但当我们关闭并重新打开游戏时，它再次显示错误，需要安装MS Visual C++。

### 修复/解决方案：

1. 从[此处](https://www.techpowerup.com/download/visual-c-redistributable-runtime-package-all-in-one/)下载 Visual C++ Redistributable Runtimes All-in-one/：https://www.techpowerup.com/download/visual-c-redistributable-runtime-package-all-in-one/ 2. 解压 .zip 并运行“install_all.bat”以自动安装所有 C++。 3. 安装完每个软件包后，只需重新启动您的电脑即可。 **还没修好？ **查看这篇文章：[点击此处](https://www.epicgames.com/help/en-US/c-Category_EpicGamesStore/c-EpicGamesStore_ErrorCodes/how-do-i-fix-the-necessary-preventions-have-failed-to-install-error-or-su-pqr-su-pqe-error-a000084866) 就是这样！我希望它对您有所帮助:) 现在您的游戏应该可以正常运行了。如果您需要任何帮助，这里是所有********我的社交***：**https://linktr.ee/alexjr977**

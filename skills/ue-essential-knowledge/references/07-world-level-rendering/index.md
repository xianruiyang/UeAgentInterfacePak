# 世界、关卡与渲染

## 覆盖范围

- World、Level、Actor、Component、Transform、Bounds。
- Camera、Viewport、Post Process、Lighting、Reflection、Shadow。
- Lumen、Nanite、Virtual Shadow Map、Distance Field、Fog、Water 等渲染相关概念。

## 阅读时机

- 需要搭建或修改关卡、相机、灯光、后处理、渲染验证场景。
- 视觉结果和资产/材质读回不一致，需要排查渲染路径或视口状态。
- 任务涉及空间构图、相机截图、遮挡、尺寸、反射或性能表现。

## 后续填充位置

- Level 与 World 状态读回规则。
- Camera/viewport 截图验证流程。
- Lumen 与反射常见限制。
- Bounds、LOD、Nanite 与可见性排查。

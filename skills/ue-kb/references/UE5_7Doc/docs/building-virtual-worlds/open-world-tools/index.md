# 开放世界工具

> 路径：虚幻引擎5.7文档 / 构建虚拟世界 / 开放世界工具

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/open-world-tools-in-unreal-engine

虚幻引擎5是一款性能强大的引擎，能够渲染充满复杂动植物的大规模开放世界。开放世界工具可用于在大型场景中程序化地填充静态网格体资产，以便创建自然而生动的户外空间。

- [草地工具快速入门](grass-quick-start/index.md) - 了解如何在地形上添加草地纹理。

- [开放世界工具属性参考](open-world-tools-property-reference/index.md) - 开放世界工具的属性和说明的列表。

- [开放世界场景工具提示和技巧](open-world-tools-tips/index.md) - 充分使用开放世界场景工具的提示和技巧合集。

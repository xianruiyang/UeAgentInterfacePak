### UE 中的动画重定向：从 Mixamo 到 Metahuman |内腔静脉VR

本文旨在指导您了解在虚幻引擎 (UE) 中配置动画重定向器的关键原则，包括添加 IK 组件以及设置从一个骨架到另一个骨架的重定向过程。动画重定向是各种项目中的重要工具，它提供了一种灵活有效的方法来在不同骨架之间重用动画，从而节省宝贵的时间并避免从头开始创建动画。作为示例，我们将演示如何使用 UE 将动画从 Mixamo 重定向到 Metahuman。在本例中，我们已将艺术家的自定义骨架网格物体之一导入 Mixamo 系统中。但是，模型的具体情况可能因项目而异。

![教程图片](assets/unreal-engine-animation-retargeting-in-ue-from-mixamo-to-metahuman-icvr/image-01.jpg)

首先，我们需要为每个骨架网格物体创建一个 IK 重定目标器。让我们从超人类（MetaHuman，简称MTH）开始。首先找到用于 MTH 的骨架网格物体。为此，请打开 MTH 蓝图，找到 Body 组件，然后导航至其骨架网格物体。

![教程图片](assets/unreal-engine-animation-retargeting-in-ue-from-mixamo-to-metahuman-icvr/image-02.jpg)

![教程图片](assets/unreal-engine-animation-retargeting-in-ue-from-mixamo-to-metahuman-icvr/image-03.jpg)

接下来，右键单击骨架网格物体附近的空白区域，然后导航到“动画”->“IKRig”->“IKRig”。

![教程图片](assets/unreal-engine-animation-retargeting-in-ue-from-mixamo-to-metahuman-icvr/image-04.jpg)

给 IK 装备一个合适的名称；为了清楚起见，通常最好使用资产名称（例如 IK_mMedNrwBody）。然而，在本例中，为简单起见，我们以超人类命名 IK 装备。

![教程图片](assets/unreal-engine-animation-retargeting-in-ue-from-mixamo-to-metahuman-icvr/image-05.jpg)

打开 IKRig 并将骨架网格物体拖到预览资源设置中。

![教程图片](assets/unreal-engine-animation-retargeting-in-ue-from-mixamo-to-metahuman-icvr/image-06.jpg)

此后，装备将被分配给给定的骨架网格物体（以下简称 SK）。

![教程图片](assets/unreal-engine-animation-retargeting-in-ue-from-mixamo-to-metahuman-icvr/image-07.jpg)

确保保存资产。之后，您可以开始配置重定向链。第一步是设置重定位根，在本例中是骨盆骨骼。为此，请在左侧的骨骼层次结构中找到骨盆骨骼，右键单击它，然后选择“设置重新定位根”。

![教程图片](assets/unreal-engine-animation-retargeting-in-ue-from-mixamo-to-metahuman-icvr/image-08.jpg)

之后，我们将看到一条指示，表明该骨骼已被设置为重定向根。

![教程图片](assets/unreal-engine-animation-retargeting-in-ue-from-mixamo-to-metahuman-icvr/image-09.jpg)

现在我们可以开始设置重定向链。重定位链定义骨骼之间的链接，具有指定的起点和终点，允许系统在动画期间自动处理中间骨骼的移动。通过创建这些链，我们告诉引擎特定的骨骼序列（例如右腿）一起发挥作用。将为其他骨架配置类似的链，使虚幻引擎能够在骨架之间正确传输动画。要创建链，首先选择根骨骼，右键单击，然后选择“新建重定向链”。

![教程图片](assets/unreal-engine-animation-retargeting-in-ue-from-mixamo-to-metahuman-icvr/image-10.jpg)

将出现一个窗口，提示您命名重定向链。通常保留默认名称会更方便，因为虚幻引擎可以自动识别不同身体部位的相应链。接下来，单击“添加链”，第一个 IK 链将出现在右侧。本质上，重定向器会将运动从一个骨架的根链转移到另一个骨架的根链。由于该链仅包含一个骨骼，因此运动将直接应用于它。接下来，我们将继续构建链，从主干开始——称为主干链。选择脊柱骨骼并将它们分配给链。为了简化此过程，您可以在编辑器设置中启用键盘快捷键。

然后，继续设置颈链。

### 手指

接下来，我们需要为所有手指配置重定向链。由于超人类模型包含许多矫正骨骼，特别是手指，因此更容易直接在视口中选择它们，然后在左侧面板中找到它们。我们只需要关注每个手指的三个主要骨骼。对左右手的所有手指重复此过程。通过这样做，我们成功地为超人类骨架创建了主要的重定向链。

### 用于重定位调整的全身 IK 解算器

接下来，我们需要通过添加校正 IK 解算器（特别是全身 IK）来增强 IK 重定向设置，以在动画重定向期间处理链的 IK 调整。为此，只需单击“+ 添加新解算器”按钮并选择“全身 IK”。之后将添加解算器：选择解算器，然后选择骨盆骨骼，右键单击它，然后选择“在选定解算器上设置根骨骼”。接下来，选择骨骼“hand_l”，单击鼠标右键，然后选择“新建 IK 目标”。 UE 将自动识别重定目标中的 IK 链，并立即提出将此目标与其连接。接下来，对“hand_r”执行相同的操作。接下来，'ball_r.还有'ball_l。别忘了保存。基本 IK 链现已配置完毕，您可以通过在视口中移动 IK 解算器方块来测试其功能。当您移动方块（即目标）时，IK 解算器将自动调整身体部位以跟随目标，导致链条尝试到达新位置。要重置姿势，请单击“重置”。此时，当您向上移动腿的目标时，您会注意到骨骼以不自然的方式弯曲。

### 调整脊柱设置以优化自然姿势

我们将从配置脊柱开始，这需要修改骨骼设置。选择全身 IK 解算器，然后右键单击骨盆骨骼并选择“将设置添加到选定的骨骼”。将生成新的骨骼设置参数。以下是设置的快速查找：对于骨盆骨骼，我们需要调整“旋转刚度”并将其设置为 1，以确保骨骼根本不会受到目标的影响。您会立即注意到身体位置的变化。接下来，我们将继续调整椎骨，重点关注脊柱骨骼。您会注意到躯干的位置有了显着改善。现在，我们需要调整肩膀，确保它们不会像人体一样不自然地旋转。要实现此目的，请启用 clavicle_l 和 clavicle_r 的骨骼设置。您可以立即注意到肩膀位置的变化。接下来我们要调整腿部。此时，如果将腿目标向后移动，膝盖就会不自然地弯曲。要纠正此问题，请选择 calf_l 骨骼并启用其骨骼设置。

### 骨骼旋转的首选角度

为了防止不自然的弯曲，我们将使用首选角度选项。激活它，然后指定骨骼可以旋转的轴。要识别正确的轴，请选择骨骼并在视口中仔细放大，您将能够在其中看到其局部坐标。在这种情况下，正确的轴是 Z 轴。如果难以确定，可以使用排除法对三个轴分别进行测试。一旦激活角度，您会立即注意到膝盖移动到正确的位置。您可以通过使用排除过程进一步细化此过程，为每个轴设置值 90 以排除不正确的轴。对 calf_r 骨骼应用相同的设置。接下来，我们将通过选择 foot_l 和 foot_r 骨骼来调整脚部。这次，我们将使用“限制”来限制骨骼沿所选轴的旋转。在这种情况下，我们可以检查应应用限制的轴。由于骨骼设置正确，因此限制将与膝盖的限制类似。如果需要，您还可以使用排除法。选择设置，选择适当的轴（本例中为 Z）并将限制设置为“Limited”。这些设置没有通用值，因此您需要直观地调整它们。主要目标是确保脚的位置正确。对于此示例，将最小 Z 设置为 -20，将最大 Z 设置为 2。移动滑块，目视检查更改，然后微调值，直到结果在视口中看起来正确。移动目标并观察关节如何反应。如果需要，请相应地调整值以改善运动。同样，配置另一条腿的设置。这些设置已经足够了，现在您需要以相同的方式为 Mixamo 骨架网格物体设置 IK 装备（该过程已在上面进行了说明）。结果应该是相似的。确保遵循 IK 重定向链的正确命名约定。完成后，您可以设置重定向器。在内容浏览器中，右键单击并选择动画 -> IKRig -> IKRetargeter。建议使用清晰的命名约定。

### 对齐源和目标 IK 装备

打开资产并分配将重新定位动画的 IK Rig 资产 (Mixamo)。接下来，选择要将动画复制到的 IK Rig（超人类）。在打开的窗口中，我们可以看到骨架网格物体的姿势不匹配。它们也合并在同一位置。首先，我们将超人类的 IK 装备向右移动 250 厘米，将它们分开。由于资产的绑定姿势不同，超人类的手臂处于尴尬的位置。因此，我们需要修复超人类的姿势。首先，我们需要调整 IK 链映射。导航到“链映射”选项卡并验证目标链和源链名称是否匹配。在这种情况下，存在明显的不匹配。在上面的示例中，我们故意对 Mixamo 和 Metahuman 中的 IK 链使用不同的命名约定，以演示重定向器设置期间的潜在错误。这不是一个主要问题，因为您可以通过匹配正确的名称来手动映射链。如果命名约定相同，则会自动分配映射。只需在源链中选择正确的名称，相应地映射它们，并且不要忘记保存。现在我们可以看到两个资产的姿势是对齐的。

### 测试 Mixamo 到 MetaHuman 动画传输

接下来，让我们测试动画如何从 Mixamo 转移到 Metahuman。为此，导航到资源浏览器并双击可用的动画以预览它们并查找动画播放方式上的任何差异。在这种情况下，一切都能正确播放，因为源骨架网格物体和目标骨架网格物体共享相同的姿势。但是，如果姿势未对齐，您只需单击“创建新姿势”即可为目标资产（超人类）创建新姿势。为其指定一个新名称，然后单击“编辑模式”，并使用旋转工具调整超人类演员的姿势以匹配 Mixamo 演员的姿势。为了进行更准确的调整，您可以将偏移重置回 0（删除之前应用的 X 轴上的 250 厘米偏移）。这会将演员定位在同一位置，从而更容易微调肢体位置。此外，利用不同的正交视图（顶部、正面等）以获得更好的精度。另一个关键设置是纠正根链平移，我们将通过一个不同的示例进行解释：在此示例中，尚未配置根平移，导致目标资源中的 IK 控制器骨骼在动画期间保持固定，这是不应该发生的。如果装备和动画蓝图 (ABP) 依赖于这些 IK 骨骼，则可能会导致问题。为了避免这种情况，请将模式设置为“全局缩放”。现在 IK 骨骼跟随骨骼。这同样适用于超人类。

应用这些设置后，您可以查看如何重新定位动画并使用 IK 全身 IK 对其进行微调。例如，在这种情况下，您会注意到右臂的旋转稍微超出了所需的限制。要纠正此问题，请转到“链映射”选项卡并选择必要的链。在这种情况下，右臂。接下来，在“详细信息”面板中，重点关注 IK 选项。例如，**混合到源**选项可调整目标位置以匹配源资源的位置。在我们的例子中，由于 Mixamo 角色有额外的装备，因此它的手臂距离身体更远。通过将该值设置为更接近 1，我们可以将超人类的手臂移离身体更远。为了纠正手的位置，我们需要将 Y 轴上的 **静态旋转偏移** 设置为 26.6。使用静态偏移参数，我们可以调整目标的位置，使 IK 影响整个手臂。例如，如果您使用的是全尺寸突击步枪而不是紧凑型 CQB 步枪，则需要将左手沿着前握把移动得更远。为此，选择目标 IK 控制器并修改必要的位置。为了更轻松地进行调整，您可以使用正交视图。此外，IK 偏移可以对具有不同高度和比例的角色进行精确的动画调整。现在，一切都已准备就绪，可以保存超人类的动画了。为此，请返回“资源浏览器”选项卡并单击“导出选定的动画”按钮。将出现一个**保存资源**窗口，允许您设置文件的前缀或后缀。确保遵守正确的命名约定并维护项目结构。选择所需的位置，然后单击“**导出**”，您的新动画将被保存并可供使用。

### 自动重定向器

现在，让我们以 Mixamo 动画为例来探索自动重定向器。首先选择所需的动画并将其导入引擎：右键单击该动画并选择“重新定位动画”。将打开一个重定向窗口。选择要将动画重定向到的骨架网格物体，并确保启用生成自动 IK 重定向资源的选项：接下来，选择适当的骨架网格物体并指定它。然后，从列表中选择所需的动画。正如您所看到的，即使骨骼之间存在差异，重定向功能也能顺利运行：手指运动也能正常运行。接下来，我们只需要保存重定向的动画。如果需要，我们还可以保存 IK 重定向器：我们还可以直接从资源窗口创建自动 IK 重定向器：

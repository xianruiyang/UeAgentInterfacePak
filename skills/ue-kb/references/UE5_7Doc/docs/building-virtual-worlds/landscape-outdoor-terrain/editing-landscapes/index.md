# 编辑地形

> 路径：虚幻引擎5.7文档 / 构建虚拟世界 / 地形户外地貌 / 编辑地形

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/editing-landscapes-in-unreal-engine

创建地形之后，即可使用以下工具对其进行定制：

- 在

  雕刻

  模式中修改其形状。
- 在

  绘制

  模式中修改其视觉外观。
- 变更用于修改地形形状和外观的

  笔刷

  尺寸、形状和类型。
- 在

  管理

  模式中修改其组件尺寸和形状。
- 使用

  地形小工具

  对地形高度图的部分进行复制、粘贴、导入和导出。
- 修改地形的

  材质

  。
- 为地形中使用的线性特征创建

  样条

  。
- 为地形中如洞窟之类的地貌特征创建

  洞穴

  。

可在 [创建地形](../creating-landscapes/index.md) 中查阅关于地形创建的信息。

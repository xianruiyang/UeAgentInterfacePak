由于影片渲染队列作为虚幻引擎编辑器或运行时应用程序中的插件运行，因此寻址路径的方式与游戏空间相关。在虚幻引擎内部，当我们发布时，我们在编辑器中看到的 Content 文件夹将更改为 Game。当我们将游戏引擎用于非游戏时，这是一个需要理解的基本概念。当我们整理和打包要发布的内容时，内容会经过高度优化和结构化，以便在控制台和硬件平台（包括 PC、Linux 和 Mac）上执行。这就是游戏文件夹概念如此重要的原因。项目的相对路径基于目标上运行的项目根目录。当您绞尽脑汁思考为什么斜杠需要以某种方式或者为什么一行是本机操作系统语法中可执行文件的路径时，请记住这一点。这就是系统以最佳方式进行通信的方式。

### 在影片渲染队列中创建渲染作业

要加载“影片渲染队列”面板，请转至顶部的虚幻编辑器菜单，然后选择“窗口”>“过场动画”>“影片渲染队列”。注意：如果缺少此选项，请确保已为您的项目加载电影渲染队列插件。在“影片渲染队列”面板的左上角，有一个“+渲染”菜单，其中将显示渲染序列列表。在此示例中选择 CameraMove001 序列。

### 配置渲染作业的设置

在渲染作业的“设置”列中，选择当前列出“未保存的配置”链接的位置。这将打开“设置”窗口，在其中执行渲染作业设置的配置。对于此示例，我们将使其保持非常简单，但在本教程的渲染预设部分中，有有关如何配置高级选项的信息。

### 存储影片渲染队列

如果项目只需要连续批处理许多渲染任务，则电影渲染队列具有可以像预设一样存储和操作的队列资源。如果您有许多类似类型的作业并且只需要更改设置或小细节，这也很有用。来自官方文档：您还可以从工具栏将当前作业列表保存为队列预设资产。单击“加载/保存队列”按钮，然后选择“另存为资源”。然后，系统将提示您命名 Movie Pipeline Queue 资源并将其保存在项目中的某个位置。该预设现在将列在“加载/保存队列”按钮下。选择它将设置您的作业列表以匹配保存的预设。这会将队列的副本导入作业区域，并且对作业列表所做的更改不会影响资产，除非您选择另存为资产并保存现有预设。在此示例中，我们将使用这些队列对象来执行最简单的渲染命令。让我们将渲染队列保存为 myRenderQueue 以供将来使用。

### 流程管理

虚幻引擎的安装文件夹中有两个不同的可执行文件。后缀“-Cmd”表示虚幻引擎的命令行开关和独立执行的首选可执行文件，而另一个 UnrealEditor.exe 是我们通常启动和创建的完整编辑器。使用“UnrealEditor-Cmd.exe”而不是“UnrealEditor.exe”。这可确保 Unreal 在启动它的进程中打开，而不是在新进程中打开。如果您要将控制台输出通过管道传输到父控制台窗口等，这是必需的。这些可执行文件可在虚幻引擎安装路径的 Engine\Binaries\platform 文件夹中找到。影片渲染队列确实支持简单的命令行参数，但它具有高度精简的命令集。包含的命令集仅采用关卡序列和主配置，或者采用队列资源（将使用保存到 MRQ 队列中的预设进行渲染）。

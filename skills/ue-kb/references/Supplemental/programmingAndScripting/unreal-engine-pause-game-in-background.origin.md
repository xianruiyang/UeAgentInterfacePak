# 在后台暂停游戏

## 来源与状态

## 运行时分类

## 摘要

关于如果玩家最小化游戏窗口或按 Alt+Tab 退出游戏时我们如何暂停游戏的简短教程。本教程需要 C++。免责声明：我只在桌面 PIE（Windows 和 Linux）和打包游戏中尝试过这种方法，而不是多人游戏或其他设备（例如移动设备）（这应该仍然有效，但我不能保证是否有效）！

## 中文整理

### 概览

本教程假设您已将 C++ 添加到您的项目中，并且您知道如何将 C++ 与虚幻引擎结合使用。您可能会注意到，您的虚幻项目仍将在后台运行（例如，如果您按 Alt+Tab 退出视口或将其最小化）。如果游戏/引擎在后台，**编辑器首选项**中有一个选项可以降低引擎的帧速率：编辑器首选项 -> 常规 -> 性能 -> 在后台使用更少的 CPU 对于某些项目，这可能还不够。您可能需要暂停游戏。本教程将探讨如果玩家最小化（或按 Alt-Tab 键退出）游戏，我们如何暂停游戏。

### 检查游戏是否在前台（需要 C++）

首先，我们需要检查游戏是否在前台或后台运行（本教程的主要部分）。我在蓝图中找不到任何执行此操作的自定义函数 - 我认为不存在。所以我创建了自己的（非常简单的）C++ 函数。

### 创建自定义函数

我将使用函数库来组织我的代码。您可以随意组织您的代码。我的 **标头 (.h) ** 文件如下所示：

**标头 (.h)**

```cpp
#include "Kismet/BlueprintFunctionLibrary.h"

UCLASS()
class MyProject_API UMyFunctionLib : public UBlueprintFunctionLibrary
{
    GENERATED_BODY()

public:

    UFUNCTION(BlueprintPure)
```

我使用了 **static ** 函数，因为我想在不引用父类的情况下调用此函数（这通常是我在创建 C++ 函数库时所做的操作）。在 UFUNCTION 宏中，我添加了 **BlueprintPure** 以在不使用执行引脚的情况下调用该函数。您可以根据需要自定义此功能。我已调用我的函数 **GetViewportFocus**。该函数具有 void 返回类型并包含一个参数“bool& isFocused”。由于**&**符号没有**const **关键字，因此该参数将是蓝图节点上的输出。这只是在蓝图节点上自定义返回值的名称。

### 功能定义

现在将主要代码添加到我的“GetViewportFocus”函数中。在相应的**源（.cpp）**文件中我添加了以下代码：

**源代码（.h）**

```cpp
void UMyFunctionLib::GetViewportFocus(bool& isFocused)
{
	if (GEngine) {
		isFocused = GEngine->GameViewport->Viewport->IsForegroundWindow();
	}
}
```

“GEngine”显示为 if 语句的 **条件 **，因为“GEngine”有时会返回无效指针。 “视口”是本地播放器的特定于平台的视口。该变量的描述可以在文件“**GameViewportClient.h**”中的引擎源代码中找到：“此视口客户端附加到的特定于平台的视口”此描述提到**客户端**，因此我假设此函数将返回**本地玩家的视口**（例如，这对于多人游戏很有用）。函数“IsForegroundWindow”用于判断游戏是否在前台运行，返回一个bool（如果游戏在前台则返回true）。

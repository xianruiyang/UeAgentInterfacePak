# GL传输格式（glTF）

> 路径：虚幻引擎5.7文档 / 管理内容 / GL传输格式（glTF）

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/the-gl-transmission-format-gltf-in-unreal-engine

GL传输格式（glTF™）是一种可扩展的开放标准文件格式，由Khronos Group开发和维护。它设计用于创建可快速加载并完全表示场景的紧凑文件。

![glTF和glTF徽标是Khronos Group Inc.的商标](../../../assets/images/03/03b5c38076ff6d791b20fdcf75242f4d00792ce157de569ebf97c1711f0298ad.png)

glTF和glTF徽标是Khronos Group Inc.的商标

glTF格式用于在广泛的应用程序之间共享丰富的3D内容，包括虚幻引擎、Twinmotion和Sketchfab，这些应用程序可以导入和导出glTF内容。

[游戏能力系统插件](https://dev.epicgames.com/documentation/en-us/unreal-engine/gameplay-ability-system-for-unreal-engine) - 属性、能力、效果、提示（Vfx / Sfx）等 1. 示例项目： [Lyra](https://www.fab.com/listings/93faede1-4434-47c0-85f1-bf27c0820ad0)、[远古之谷](https://www.fab.com/listings/0c19880e-21bd-42ba-8287-1caccc3951b1)、[动作角色扮演游戏（旧）](https://www.fab.com/listings/ef04a196-03c1-4204-998a-c7d5264fade7) 2. [Tranek 的气体文档](https://github.com/tranek/GASDocumentation) 3. [Kaos Spectrum](https://www.thegames.dev/) 2. [目标系统插件](https://dev.epicgames.com/documentation/en-us/unreal-engine/gameplay-targeting-system-in-unreal-engine) - 数据驱动的定位（跟踪和重叠）请求（目标检测） 3. [游戏功能插件](https://dev.epicgames.com/documentation/en-us/unreal-engine/game-features-and-modular-gameplay-in-unreal-engine) - 定义您的模块化游戏功能并随时激活/停用 4. [游戏摄像机系统](https://dev.epicgames.com/documentation/en-us/unreal-engine/gameplay-camera-system) - 定义复杂的摄像机行为 5. [Mass AI、实例化 Actor 和区域图](https://dev.epicgames.com/documentation/en-us/unreal-engine/mass-entity-in-unreal-engine) -面向数据的设计（类似于实体组件系统（ECS）） 6. [智能对象](https://dev.epicgames.com/documentation/en-us/unreal-engine/smart-objects-in-unreal-engine) - 玩家和AI可交互对象的交互（预约）系统 7. [Mutable](https://dev.epicgames.com/documentation/en-us/unreal-engine/mutable-overview-in-unreal-engine) - 在运行时 8 中创建模块化角色。 [通用 UI](https://dev.epicgames.com/documentation/en-us/unreal-engine/common-ui-plugin-for-advanced-user-interfaces-in-unreal-engine) - 创建游戏/平台独立 UI

### 关卡设计

1. [程序内容生成 (PCG)](https://dev.epicgames.com/documentation/en-us/unreal-engine/procedural-content- Generation--framework-in-unreal-engine) - 使用程序生成工具创建关卡 2. [几何脚本](https://dev.epicgames.com/documentation/en-us/unreal-engine/introduction-to-geometry-scripting-in-unreal-engine) - 通过编码创建几何体/网格/模型（即蓝图） 3. [脚本化工具](https://dev.epicgames.com/documentation/en-us/unreal-engine/scriptable-tools-system-in-unreal-engine) - 创建并自定义您的关卡设计工具 4. [水](https://dev.epicgames.com/documentation/en-us/unreal-engine/water-system-in-unreal-engine) - 创建水元素（河流等）和浮力

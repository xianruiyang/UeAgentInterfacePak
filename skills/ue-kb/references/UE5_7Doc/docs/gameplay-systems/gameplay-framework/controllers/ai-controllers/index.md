# AI控制器

> 路径：虚幻引擎5.7文档 / Gameplay系统 / Gameplay框架 / 控制器 / AI控制器

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/ai-controllers-in-unreal-engine

**玩家控制器**依靠人类玩家来制定决策，而**AI控制器**则侧重通过环境和游戏世界中的输入来做出响应。 AI控制器的任务是观察周遭的世界，相应作出决策，无需人类玩家的控制。

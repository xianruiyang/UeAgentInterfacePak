# 面向Maya用户的虚幻引擎动画制作入门

> 路径：虚幻引擎5.7文档 / 入门指南 / 面向Maya用户的虚幻引擎 / 面向Maya用户的虚幻引擎动画制作入门

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/getting-started-animating-and-rendering-in-unreal-engine-for-maya-users

本指南为希望以最简单快捷的方式开始学习虚幻引擎动画制作的新用户设计。 本指南将逐步引导你完成安装引擎、创建项目并使用现有示例内容进行实践。

目标：

- 安装虚幻引擎并使用现有示例设置项目
- 使用Sequencer为控制绑定对象制作动画
- 使用动画工具微调带动画的序列的关键帧
- 为场景添加光照和渲染元素
- 使用虚幻引擎的影片渲染管线输出最终图像或视频序列

### 推荐阅读

如果你此前未使用过虚幻编辑器，为更好地使用本指南并熟悉其界面，建议先阅读"面向Maya用户的虚幻编辑器和功能概述"。 该指南旨在帮助你在较短时间内熟悉虚幻引擎的各个组件，并找到Maya与虚幻引擎在专业术语、技术概念及操作流程上的关联。

- [面向Maya用户的虚幻编辑器和功能概述](../unreal-editor-and-features-overview-for-maya-users/index.md) - 面向Maya用户的虚幻引擎核心功能指导概述。

- [安装虚幻引擎和设置项目](installing-and-setting-up-a-project/index.md) - 安装虚幻引擎和设置项目的指南。
- [如何使用Sequencer制作动画](how-to-animate-with-sequencer/index.md) - 如何使用关卡序列设置场景并为控制绑定角色制作动画。

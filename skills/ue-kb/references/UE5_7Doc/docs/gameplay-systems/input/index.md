# 输入

> 路径：虚幻引擎5.7文档 / Gameplay系统 / 输入

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/input-in-unreal-engine

**玩家输入（PlayerInput）** 对象负责将来自玩家的输入转换为Actor（如PlayerControllers或Pawn）可以理解的数据。 PlayerInput是输入处理流程的一部分，通过玩家输入映射和输入组件，将玩家的硬件输入转化为游戏事件和运动。

你可以从[输入概述](input-overview/index.md)开始学习，或者选择下文中的主题开始学习。

# 虚幻引擎 5.4 ！真实 PCG 建筑 - 教程第 2 部分！

## 知识目标

- 围绕“虚幻引擎 5.4 ！真实 PCG 建筑 - 教程第 2 部分！”整理真实 PCG 建筑生成第 2 部分：在单层框架基础上引入点类型、过滤、楼层复制、首层特殊高度、门窗重复和属性输出，让建筑可以生成多楼层立面。

## 可复现主流程

- 接上第 1 部分的单层 Subgraph，先清理临时调试位移和不再需要的直接生成节点。
- 为 Corner、Pillar、Wall 等点写入 Target/Type 属性，不在 Subgraph 内直接生成 Mesh。
- 在主图中用属性过滤拆分不同点类型，再分别接对应的 Static Mesh Spawner。
- 确认 Cell Z Size 与 Ceiling Height 对齐，让每层高度可控。
- 在建筑蓝图中增加 Position/Floor 相关变量，为多楼层复制和索引判断做准备。
- 用 Attribute Noise 或随机属性控制局部变化，但要保证重要结构点不被错误过滤。
- 复制单层点集并保留 Index/Floor 属性，使每层能知道自己属于第几层。
- 处理首层特殊高度：首层可以比其他楼层更高，其余楼层使用统一 Ceiling Height。
- 用 Get Actor Property 从蓝图读取建筑总高度、楼层数和其他外部变量。
- 沿 Z 轴复制 Transform Points 和 Spawner，形成多层建筑立面。
- 建立 Door Repetition、Window Repetition 等重复参数，控制门窗间隔和数量。
- 通过索引减法、取模或属性比较筛选门、窗、墙、柱点。
- 把内部计算结果输出到专用属性，避免覆盖 Index 等 PCG 内置属性。
- 整理所有门窗、柱、墙分支并连接到最终 Spawner。
- 验证多楼层建筑在不同高度、重复次数和模块尺寸下仍然对齐。

## 复现检查清单

- Subgraph 只负责产出带属性的点，实际 Mesh 生成应放回主图，便于统一过滤和复用。
- Target/Type 属性值要稳定，例如 corner、pillar、wall，否则属性过滤会漏点。
- 首层高度和普通楼层高度要分开处理，不能只用一个 Ceiling Height 覆盖所有层。
- Index 是关键内置属性，不能随便覆盖；需要输出结果时用自定义属性。
- 门窗重复参数要和墙体长度、模块长度匹配，否则会出现不完整或错位开窗。
- 复现时先固定随机种子，再调整密度、过滤和生成资源，避免随机结果掩盖逻辑错误。

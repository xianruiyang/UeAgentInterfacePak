# 测试并优化你的内容

> 路径：虚幻引擎5.7文档 / 测试并优化你的内容

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/testing-and-optimizing-your-content

**虚幻引擎** 包含了很多工具和功能，能帮助开发者测试并优化应用程序，以便达到目标帧率和高质量的体验。

要了解更多信息，请阅读以下主题。

## 主题

- [Gameplay调试程序](using-the-gameplay-debugger/index.md) - 用于在运行时分析实时游戏的工具。

- [使用Oodle](using-oodle/index.md) - 介绍虚幻引擎中的Oodle压缩解决方案

- [控制台变量编辑器](console-variables-editor/index.md) - 介绍如何使用控制台变量编辑器可以查看并修改项目中使用的所有控制台变量，以及如何将控制台变量设置保存为预设，并在不同项目间共享。

- [崩溃报告](crash-reporting/index.md) - 了解崩溃报告以及如何在你的项目中使用崩溃报告器。

- [PSO缓存](optimizing-rendering-with-pso-caches/index.md) - 提前记录应用程序的GPU状态，优化渲染。

- [Significance Manager](significance-manager/index.md) - 使用Significance Manager以为项目量身打造的方式调整性能

- [Stat命令](stat-commands/index.md) - 专门针对显示游戏统计的控制台命令。

- [Unreal Insights](unreal-insights/index.md) - 使用Unreal Insights对你的项目进行解析。

- [Zen Loader](zen-loader/index.md) - 介绍虚幻引擎5的运行时加载程序。

- [自动化系统概述](automation-test-framework/index.md) - 概括叙述用于单元测试、功能测试和内容压力测试的自动化系统。

- [统计数据系统概述](unreal-engine-stats-system-overview/index.md) - 开发者可通过统计数据系统收集和显示性能数据，从而优化游戏。

- [低级别测试](low-level-tests/index.md) - 面向轻量级、以模块为中心的测试的框架。

- [可视记录器](visual-logger/index.md) - 采集Actor的状态然后在游戏或编辑器中可视化显示此状态的工具。

- [Clang检测工具](using-clang-sanitizers-in-unreal-engine-projects/index.md) - 在安卓和Linux项目中部署Clang检测工具来快速查找问题。

# 关卡路线结构与玩法选择

这些是路线结构与玩法选择的设计原理，不是引擎定律或固定搭建模板。适用性取决于玩法、镜头、移动能力、玩家目标和失败代价。它们既支持关卡白盒的基本空间连接，也支持美术白盒结合背景细化空间路线、具体玩法、选择的意义与探索动机；对应的[玩家引导](scene-production-stages.md#玩家引导选择确认与空间记忆)、构图、地标和照明也在美术白盒设计并落实。

下面的因果关系用于作设计选择，不是玩家必然反应的证明。静态形体与布置能说明可见关系；实际通行、AI行为、交互、难度及首次理解需要各自的有效证据。熟悉路线的制作者试跑可说明该次流程表现，不能直接代表陌生玩家的首次理解或教学效果。阶段交付与回流由[场景三阶段](scene-production-stages.md#阶段衔接与回流)维护，不在这里增加测试轮次或审批。

## 路线结构与体验

把区域看作节点，把可通行连接看作边，有助于分清“空间靠近”和“真正相通”。连接还可能带方向、开关、钥匙、能力或运行时机等条件。平面上的交叉不一定连通；视觉上能看到的目标也不一定已经可达。

| 结构 | 主要作用 | 容易混淆之处 |
| --- | --- | --- |
| 主线 / Critical path | 承担完成目标必经的进展与信息 | 主线不一定是最长、最宽或唯一的路径 |
| 支路 | 提供奖励、信息、战术位置、额外挑战或空间体验 | 只有入口数量增加、选择结果没有差别，不等于有意义的分支 |
| 合流支路 | 从主线分出，以不同体验抵达后续关键节点 | 合流后应容易重新理解当前目标；支路不必每条都返回原入口 |
| 回环 / Loop | 通过另一条连接回到已知区域，改变对空间的理解或利用方式 | 绕一圈没有新信息、收益或路线作用，可能只是多走路 |
| 捷径 / Shortcut | 解锁后减少时间、风险或重复内容，改变后续行程 | 距离短不代表体验好；开门动作、候梯和装卸时间也计入通行成本 |
| 枢纽 / Hub | 让多条路线共享可辨认的参照和决策位置 | 多个相似出口挤在一起会增加记忆负担，而非自然提高探索性 |

“中等规模”没有统一的房间数、Actor 数或面积。更有意义的是必经流程、决策数量、探索范围、遭遇与休息的变化，以及首次通行和重复通行的成本。单纯拉长走廊或反复爬同一种楼梯只会增加时长。

### 路线开启顺序

有条件的连接应结合首次到达、条件满足后和再次返回时的状态理解：玩家能看见什么，当前能走哪里，从哪一侧可开启，以及在哪里取得条件。同一张全部开启后的连通图，不能代表初次探索的选择。门、机关或落差的位置与方向会决定先经历哪些空间、从何处认识另一侧，并影响开启后是否能理解新连接的价值。

设计分支时结合这些状态安排信息、收益和挑战，使玩家理解当前选择的意义及尚未完成的可能；不把未开放的必经路与不可交互布景混为一谈。中间目标、人物协作和开启条件应有场所依据，并带来有意义的观察、行动或变化；增加依赖环节本身不会改善体验。开启反馈应能与已见过的目标、阻隔或地点联系，不套用固定门锁顺序或制造反复跑腿。合理的替代路线可以保留；判断绕过某条件是否有问题，要看它是否破坏关键状态或已约定目标，不能只因偏离预想走法就封路。

路线开放也应与人物事件的前提、变化和回访目的相容。明显可走的路径会邀请玩家继续前进；若事件期待先离开这条路、去别处再返回，就需要可理解的理由，不能只依赖制作人员预设的顺序。结合实际可能的访问次序，让人物位置、交流内容和事件状态承接合理探索，或通过有依据的开启条件组织顺序，不默认用锁钥限制自由。有意错过、分歧或时限可以保留，但应按其发现难度提供相称的线索与后果反馈，区分预期分歧和无意断线。回访时携带的新信息、物品或关系变化，也能使熟悉地点获得新的行动目的。

## 玩家探索倾向：用条件解释，不作统一排序

| 倾向 | 对设计的启发 | 适用条件与反例 |
| --- | --- | --- |
| 可见与可发现 | 入口、轮廓、声音、视线和环境痕迹能让玩家知道某处值得探索 | 隐藏区域也可先通过间接线索被推知；“看不见就绝不会探索”过于绝对 |
| 向前推进 | 连续的空间方向与前景目标有助于保持动机 | 已知的奖励、任务返回和安全需求可能让主动回头很合理 |
| 补完当前区域 | 已发现且仍有可感知目标的小支路，会使玩家希望先完成再离开，避免以后再找 | 未发现、已探明、新区域和未完成是不同信息；已探明也可能未完成，不把补完等同于杀光或搜光。时间压力、强目标或预计支路过长会改变选择 |
| 就近与同层 | 近处、同一高度、低操作成本的入口更容易先被尝试 | 远处地标、上层奖励或熟悉的目的地可以压过距离优势 |
| 追求收益 | 预览奖励、资源、知识或战术优势能说明绕路价值 | 价值是玩家感知的；纯装饰金光不等于玩家已经理解收益 |
| 规避损失与不确定性 | 危险、失去进度和看不见退路会提高进入门槛 | 熟练玩家、挑战目标或可靠高收益也可能主动吸引冒险 |
| 宽窄感受 | 宽路往往显得更易通行，窄路可能增加受限与受袭感 | 掩护、敌人射界、玩法习惯可能让狭窄路径更安全；实际净空与视觉宽度也不同 |
| 高差与不可逆下落 | 无法看清落点、返程或伤害时，玩家更容易犹豫 | 有清晰落点、已学会的下落规则或可靠回程时，下行也可成为自然主线 |
| 敌人强弱 | 可读的敌人能力与空间优势会影响接战或绕行 | “见弱就打、见强就逃”不能覆盖潜行、资源不足、任务要求和个人偏好 |
| 明暗与对比 | 其他条件相近时，局部亮处通常比暗处易吸引注意；颜色和运动也可帮助标记入口 | 注意不等于选择；潜行中暗处可能安全，强光中可能有威胁。全场都亮会削弱层次 |

这些倾向相互竞争，不合并为统一排序。例如亮而有敌的主路与暗而有奖励的支路，要结合当前目的、已知风险和回返成本判断。是否已知、是否新鲜和是否完成也是不同信息；设计关注玩家此刻知道什么、想得到什么、担心失去什么，以及能判断多少行动后果。

## 局部决策与引导

设计同一空间时，把实际通行与观察关系、玩家能获得的信息，以及行动前后的状态共同考虑。来向、高差、开口和遮挡决定能接近或看见什么；已有经验、线索和反馈影响如何理解；能力、资源、门禁及人物状态决定当时可采取哪些行动、行动后改变什么。用这些关系一起安排目标、威胁、设施与退路，沿现有路线、布局和玩法说明表达，不要求逐房间填写固定状态表。空间需要符合场所用途与事件背景，不能只为拼接目标链任意放置机关或人物。

入口的可见性、可达性、收益和风险是不同信息；看见目标不代表理解如何到达，发现路径也不代表愿意承担代价。结合实际来向区分哪些信息可直接辨认、哪些可由线索推测、哪些有意暂时未知，让玩家有依据选择行动而不必提前知道全部后果。明确奖励、好奇、人物线索或空间变化都可提供接近理由；未知不自动产生紧张，已知危险也可因位置、资源和操作条件形成取舍。

跳落、深入难以退出的支路或消耗稀缺资源，可能使玩家承担不可逆或较高的行动承诺。结合游戏约定、先前经验和可见线索，让玩家对落点、风险、返回条件及失败后的重试成本形成与预期发现难度相称的判断。可以保留未知和惊喜，但要区分有依据地接受风险与误以为能轻易退出；后置奖励不能自动解释前面的误导或额外负担。回报与投入的联系见[节奏与学习](#节奏与学习)，不要求事先揭示全部收益或后果。

同一空间的不同入口可能改变进入高度、首见威胁、掩护、出口可见性和可用退路。设计这些来向时，将到达入口所需的绕行、风险及开启条件，与入场后获得的信息或战术优势一起考虑；场内路线较短不代表整段行程代价较低。不要求所有入口等价或同样显眼，但不能用一个正面入口的体验代替其他实际可用来向。

开口构图、路径延续、地标、光声对比、角色动向和奖励共同引导注意。它们可以指向目的地，也可以让玩家回看、检查边角或推知另一层空间，但应结合场所活动与真实可达关系安排。文字或NPC交流可补充行动目的、条件和背景；具体可走方向仍要在空间中可辨。机关路线还包含等候、登乘、对端落脚和离开，远处地标不能代替被遮挡后的局部线索。

转折、遮挡或状态变化后，以适合当前目标的空间、行为或声光反馈说明发生了什么、接下来有哪些可能；幕后条件改变而玩家无从察觉，不能算推进已经被理解。有意隐藏的支路通过相应线索表达探索可能。多个亮点、奖励或敌人会竞争注意，应从当前视角组织其主次，给必要观察留下时间和注意余地，而不是逐件追求显眼。奖励的预览、抵达路径与取得后的反馈也要相容。

同一提示的意义还取决于访问经历：玩家先去过哪侧、取走了什么、开启了哪条连接，以及当前想继续推进还是返回。初访时有用的光点或目标，重访时可能消失、重复吸引或把注意带离当前去向；设计要比较会改变选择的实际访问顺序，不能只假定一条理想首访路线。可通过不同来向可见的线索、状态反馈或仍可辨认的空间参照承接，不要求所有提示随访问动态变化。支路可以弱提示，返程方向也可在初访时不占主导，但提示强弱应符合当时目标与发现难度，不能把无意误导或误封通路解释成弱引导。

### 动作叙事与人物调度

人物关系与状态可以通过玩家参与的合作、接近、等待、共同观察及离开来表达。先明确希望玩家察觉的变化，再安排人物的距离、朝向、主动性、回应与空间条件，使行动本身承载叙事。偏离熟悉合作规则可突出变化，但已有经验只是理解依据之一，动作、声音和现场语境也可解释原因；有意迟疑或不回应应有可辨认的叙事对象与继续行动的线索，不能把操作失灵或无期限等待当作情绪表达。

注意力转移与人物调度一起设计：观察、搜寻或交互可以为人物移动和后续交流创造位置与时间，人物行动也可以引导玩家注意。双方都需有场景内的动机，关键交流按其表达方式留出可见或可听的条件与理解余地。人物到位与事件推进结合实际位置和状态，不能只押注玩家会搜刮或停留固定秒数；跳过支路、抢先前进、回头和长时间停留中确实会影响事件的情况，应由相应条件与后续反馈承接。可错过的交流仍按其叙事作用设计，不为保证演出一律封路、强迫搜刮或等待；访问顺序与事件前提沿[路线开启顺序](#路线开启顺序)处理。

### 玩家视角下的区域辨识

总图中的区域轮廓和路线，到了玩家相机高度可能被墙体、植被、地形或近景遮住。区域辨识应基于实际来向、观察距离和当时可见的信息：玩家如何认出所处场所、区分关键出口，并把局部线索与目的地联系起来。一个入口有光或一个物件醒目，只能说明局部可能受到注意，不能证明整个区域可辨。

重复构件可以维持建筑语言，关键差异则应来自用途、体量与轮廓、开口关系、层次或照明等可感知的组合。要考虑地标在首次进入、交战后转向和反向回返时是否仍有识别依据，以及它与可选路线的位置关系；不能只依赖制作人员熟悉的俯视形状、路线编号或玩家看不见的正面。同类场所可以相似，必要的方向差异也不必靠每处更换主题或堆装饰制造。

### 可行走表面的表达

可通行的窄边、屋面、坡道或平台需要让玩家从实际接近位置辨认其承托面、边界、连续方向及下一落脚处。形体、开口、材质或色彩差异、使用痕迹和照明可共同表达通行可能，并与真实尺寸、碰撞、角色能力及连接状态相容；这些线索不能代替通行条件本身。同一行动含义尽量采用可学习的表达，避免装饰面反复给出与通路相同的强提示；不规定统一颜色，也不要求所有隐藏路线直接显露。

能站立、能继续前进和能安全返回是不同信息。跳落或跨越结合起点、落点、遮挡和已知动作规则表达风险，不能让一个亮边同时承诺全部结果。线索来自合理的建筑或地形关系；美术白盒用简化形体与色块表达，但制作分区颜色不自动具有玩家可理解的通行含义，后续资产替换需承接已建立的辨认依据。尺度与实际通行条件见[白盒、通行与机关空间](blockout-and-traversal.md)。

### 目标预览与间接到达

可以先让玩家看见值得接近的目标，同时让直接通往它的路径受到可理解的限制，产生寻找另一条路线的动机。目标可以是奖励、人物、设施、目的地或尚未理解的事件；其轮廓、活动或已知意义要足以使玩家在初见时产生兴趣。阻隔应来自合理的空间构造或已知条件，并与实际移动能力和连接状态相符。仅展示一个隔着高差或围墙的亮点，却不给可推知的接近办法，容易成为看似不可玩的布景；任意封路也不能代替这种设计。

让可发现的绕行入口、楼层连接或开门条件与目标形成联系，不要求在首次看见时展示整条解法。路线可以暂时背离目标或将其遮住，途中通过再见目标、熟悉参照、接近过程或状态变化维持方向与进展感。绕行本身应有与场所相关的观察、选择或行动，到达后兑现先前预期的收益、交互、信息或新连接，并使玩家理解它与初见位置的关系。该方法应在空间和路线设计时组织，不能在既定走廊终点随意放一个奖励就称为完成；也不要求每个区域都设置延迟可达的目标。

## 遭遇与行动条件

先确定玩家在哪里发现威胁、能否继续观察、如何接近，以及接战、绕行或退出各有什么条件，再安排敌人和场地。并非每处都要提供全部选项；强制战斗、可选挑战和可避开的威胁需要表达各自的选择边界。敌人的位置与活动仍需符合其守卫、巡逻、觅食或其他场景职责，不能仅因方便指路就脱离场所逻辑。

区分完成当前通行或任务所需承担的风险，与取得额外物品、信息或战术收益需要增加的暴露、交战、绕行及回程代价。二者可以发生在同一场地，目标位置、威胁范围与退路共同表达这种取舍，不默认通过区域必须清空敌人或收集全部内容。若某项收益实际是后续推进必需条件，就按必经内容设计其风险与信息，不能仅标作可选奖励。是否允许绕行或撤退仍服从既定玩法，不要求每个场地都有安全路线；敌人与收益的位置也须符合场所用途。

敌人的移动、攻击来源、弹道或声音可以引起回看、追踪或寻找高处路径，但吸引注意不等于引导玩家采用预想路线。要考虑玩家能否辨认线索来源、把它与可行动的入口联系，以及受威胁时有没有观察和决策余地；同一攻击也可能使玩家直接逃离。

遭遇还会改变下一次探索的起点。根据接近、追逐、绕行或撤退的可能范围，考虑压力解除后玩家可能处于哪里、面向哪里，以及哪些出口和目标更容易被注意；不同打法可能产生不同结束位置，不能把一个预设终点当成必然结果。敌人死亡、未触发或状态改变后，动态线索可能消失，必要方向应由仍成立的空间关系或其他线索承接。引导应支持玩家重新定位，不以强迫追逐到固定点代替路线设计；这些行为假设与静态布置证据分开表达。

遭遇强度来自个体能力、数量、同时生效的射界、高差、遮挡、移动范围和退路。改变接近方向、暴露过程或机动条件，可以让已有敌人形成不同遭遇；几何条件也会影响敌人的移动和攻击，不能只考虑玩家受限的一面。玩家通过选路、观察和先手取得优势，与系统根据玩家表现自适应调整敌人参数是不同机制。按场所职责组织差异，不机械套用相同密度；轮廓、姿态和武器可以预告类别，实际能力仍由行为配置决定。

当破坏地形、移动设施或完成任务会改变可用空间时，设计要承接其对立足面、掩护、通行边界、敌我路线、退路及后续任务的实际影响。例如炸开冰面可能同时阻断追击并失去当前立足点，因而改变出手位置与时机。变化前可观察的形体、危险信号与已有规则帮助判断行动后果，变化后的反馈应让玩家辨认新的边界与机会。破坏也可只承担表现职责；是否改变通行或战术取决于既定玩法，不能从碎裂外观自行推定。

搬运等任务若限制速度、武器或交互能力，应按角色当时的可用行动判断同一路段的通行负担、暴露时间、停留节奏与应对余地。限制可以服务路线取舍，也可以表达负重、合作等叙事体验与节奏；限制方式和持续时间应依据这些目的，搬运次数本身不说明任务的丰富度。

## 垂直结构与空间记忆

垂直关卡的价值来自不同高度之间的可见、可达和状态变化。先预览另一层，后来从新高度或入口认出旧空间，可以帮助玩家把零散路径联系起来。再次经过时，应考虑玩家已经知道什么，以及新的视角、连接或状态改变了哪些可见信息和行动选择；保持可辨认的旧参照，使这些变化有比较依据。仅把同类走廊叠成多层，或原样重复同一行程，未必产生这种认识上的回报。

坡道、楼梯、梯子、电梯、机关平台、攀爬和落差会带来不同的速度、暴露时间、镜头变化和可逆性。选择取决于玩法能力及路线作用；不为凑种类加入与流程无关的设施。电梯井、桥梁和中庭还能作为跨层参照，但要区分看得到的连接与实际能走的连接。

### 全貌、局部定向与重逢

开阔视点可以先展示一部分空间关系和远期目标，建立可记忆的参照；不必一次暴露全部路线。进入封闭空间后，门洞、设备工作面、楼梯、遮挡和遭遇可以让行进与观察方向自然变化，逐步更新玩家对整体的认识。开阔段主要帮助定位和预期，封闭段主要组织局部选择与节奏，二者不以相同的转弯数量或相似走廊替代。

可以暂时削弱全局方位感，但当前出口、继续方向和可用退路仍需可理解；偶尔重见地标或已知区域能校正空间记忆。隐藏局部出口、堆同质岔道或反复强迫转向造成的迷失，不自动构成探索乐趣。路线长度与转折应由场所用途、玩法和可见信息解释。

回环的空间重逢依赖可辨认的熟悉场所与新旧路线关系。减少行程或风险是通行收益，重新认识区域关系是认知收益，二者可以分别成立。出口若只露出无辨识度的一面墙，或两条支路仅在未知区域合流，拓扑成环也缺少重逢所需的信息；帮助理解空间的连接不必宣称为高效捷径。

## 节奏与学习

探索、观察、战斗、平台操作和休整对注意力、判断与操作的要求不同。总体路线安排它们的关系，美术白盒结合场所用途，通过具体目标、视野、空间开合、暴露时间和行动条件落实变化。逐步揭示可以改变玩家对对象的认识、接近程度或参与方式；期待与消化信息也有作用，不要求每小段路都新增线索。只更换装饰、敌人数或拉长相同活动，未必形成不同体验。

缓冲空间可以承载巡视、辨认地标、整理信息、休整或共同观察，让玩家调节投入程度；不必靠没有用途的长走廊拖延，也不必用收集目标填满所有安静区域。根据叙事紧迫性与玩法决定哪些停留由玩家结束、哪些受事件限制。允许自主停留时，空间、人物行为与声音应支持继续停留，离开方式清楚，不让无关催促或过早转场抵消这一安排；不要求所有观景点无限循环。

离开和转场也是节奏的一部分：将继续方向、人物回应、视域开合、光声和环境痕迹的变化联系起来，使前后段落的差异能够被感知。明暗、上下行或宽窄本身没有固定情绪含义，取决于前后语境与玩家处境；从缓冲进入压力段仍需让行动条件可理解，不能仅为情绪反差无故拖长通道或破坏场所构造。

区域的体验差异应落在玩家为什么进入、主要观察或行动是什么，以及离开时获得了什么信息、收益或状态变化。探索回报可以是物品，也可以是新视点、对旧空间的重新理解、战术位置、新连接、人物交流或叙事发现。将它与途中付出的操作、风险和期待相联系：视点需要展示有意义的空间关系，叙事发现需要可读的场所与事件线索，抵达后应能感知自己获得了什么。无需每条支路兼具这些回报，也不能以风景替代已经承诺的物品或交互收益。

奖励的价值还取决于何时能使用。强化资源、工具或信息的获得，应结合可到达的使用地点、其他所需条件、返回成本及后续需求安排，使探索转化为新的能力或选择。新能力、资源用途或人物关系也可能改变旧空间的意义：原先无用或危险的对象，现在可能值得接近；这种回访价值仍取决于收益、行动代价和返回距离，不能仅因增加一个机制就假定成立。有意延后兑现可以维持期待，不要求奖励立即使用或每次解锁都安排回访；若后续进展依赖该收益，不能假定玩家已完成可选探索、兑换或装备。获得、兑现与后续使用的关系需要成立，单看投放数量不能说明奖励节奏。

教学设计先明确本段依赖哪些观察、操作或道具经验，以及实际可达路线此前提供了哪些理解机会。经过某区域、见过敌人或取得道具，都不等于已经学会；可跳过的支路、另一入口和重访会改变先前经验，不能把设计者选定的路线当作所有玩家的共同基础。缺少经验的进入方式可在当前空间保留观察和低代价尝试、提供符合语境的提示或其他可理解的应对，不为统一教学次序擅自封路，也不要求每次重访重做整段教学。

敌人、空间操作或机关规则是否容易被理解，取决于可观察的因果、反馈和尝试成本。首次呈现时可减少同时竞争的威胁和操作要求，让关键行为有机会被看清；后续通过已有规则的组合、场地或接近条件形成变化，并保留可识别的线索与反馈，使旧经验能帮助处理新问题。需要某种工具时，把取得、理解用途和尝试使用的机会联系起来，不能只以投放位置或数量证明教学成立。递进不固定为先单敌再多敌，也不能把更多敌人或重复受袭自动视为学会和强化。

连续遭遇要考虑同时生效的攻击、跨区域追逐、资源消耗，以及观察、回撤和恢复的余地；图上分开的两场战斗，实际可能连成一段压力。暂时安全的站位、防线或喘息可以是玩家选择与行动的回报，其作用按遭遇目标判断，不以所有位置持续受压为普遍要求。结合路线开启状态、检查点和失败后的重复通行判断负担，而不只看首次理想路线。局部段落可承担首次认识、变化应用、探索缓冲或回环收束等作用，避免相邻段落只重复同一要求或缺少信息衔接；不规定固定战斗数量、压力曲线或教学次数。

## 检查点、传送与捷径

检查点决定失败后从哪里恢复，补给决定持续推进能力，存档决定哪些进展跨会话保留，传送改变远距离通行成本；这些功能可以组合，也可以分开。

若已激活检查点之间能随时免费传送，连接相同起终点的捷径通常会减少价值。可根据目标让捷径服务未覆盖区域、战术绕行、返回途中或首次探索，也可以采用有条件的传送。限制传送只是设计选项，不能为了保住捷径价值而擅自改变已约定玩法。

考虑捷径时比较解锁前后真实行程及风险，而不只比较两点直线距离；开启时机还会改变连续探索的长度、补给机会与失败后需要重走的内容。增加连接可能减轻无意义重复，也可能过早结束原本需要维持的压力，不能按捷径数量判断节奏质量。

回到枢纽或熟悉节点后，落脚位置、出口朝向、可辨认的旧参照与当前可用连接应共同支持重新定位和下一步选择。先让玩家认出回到了哪里，再使继续推进、休整兑现奖励或回应人物事件等当前目标有相应线索；不要求所有出口同时强烈吸引，也不假定回返后一定沿首次离开的方向走。熟悉场所可以随进展承接不同目的，避免把每次返回都处理成相同的补给与折返。

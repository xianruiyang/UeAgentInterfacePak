# 虚幻引擎 5.4 ！真实 PCG 建筑 - 教程第 1 部分

## 知识目标

- 围绕“虚幻引擎 5.4 ！真实 PCG 建筑 - 教程第 1 部分”整理真实 PCG 建筑生成第 1 部分：搭建 BP Building 与 PCG Graph/Subgraph，定义建筑尺寸参数，把墙、柱、角件和楼层单元按网格尺寸和偏移规则生成出来。

## 可复现主流程

- 先建立目标建筑蓝图：用 Actor Blueprint 承载 PCG Component，并明确该蓝图要生成不同尺寸、不同特征的建筑。
- 创建建筑尺寸变量：Width、Length、Height、Wall Length、Ceiling Height 等参数要先暴露，后续网格尺寸和生成规则都从这些变量读取。
- 准备建筑模块资产：选择墙、柱、角件、基础楼层等 Static Mesh，并记录它们的真实尺寸和需要的半尺寸偏移。
- 用 Bounds Modifier 和 Difference 调整每类点的空间占用范围，避免墙、柱、角件之间互相重叠。
- 把单层生成逻辑封装为 Subgraph，并在 Graph Settings 中建立输入参数和默认值。
- 用参数驱动 Grid Extents 和点生成范围，让每栋建筑不再是固定尺寸。
- 调试 Subgraph 输入输出，确认外部传入的宽、长、高和模块尺寸能正确影响点集。
- 用 Axis Tripod/Debug 显示点方向，检查点是否位于建筑四条边和四个角的正确位置。
- 计算每段墙体的中心偏移：根据 Cell Size、Wall Length 和 Pillar Length 得到 X/Y 方向上的半尺寸位移。
- 为墙体点接 Static Mesh Spawner，按墙体方向分别生成四边墙面。
- 为柱子点接 Static Mesh Spawner，按柱子长度和墙体偏移把柱子放到墙之间。
- 为角件点计算额外偏移，解决角件不直接落在角上的问题。
- 传递 Ceiling Height、Floor Height 等属性，让单层高度和楼层厚度可以被上层图表复用。
- 把 Subgraph 参数接入主图，确认默认建筑尺寸可以生成稳定的单层框架。
- 添加 Decal 或细节装饰，让建筑不只是简单方盒。
- 验证蓝图可替换不同资产集，后续能生成不同风格、不同尺寸的建筑。

## 复现检查清单

- 墙、柱、角件的真实尺寸必须先量清楚，否则所有 Transform Offset 都会连锁出错。
- Wall/Pillar/Corner 点集必须分开调试，避免一个 Spawner 同时吃到不属于自己的点。
- Grid Extents 应由参数驱动，不要把建筑宽长写死在节点里。
- Subgraph 的输入输出和 Graph Settings 参数名称要保持一致。
- 第一部分重点是单层建筑框架，不要提前把多楼层、门窗和屋顶逻辑混进来。
- 复现时先固定随机种子，再调整密度、过滤和生成资源，避免随机结果掩盖逻辑错误。

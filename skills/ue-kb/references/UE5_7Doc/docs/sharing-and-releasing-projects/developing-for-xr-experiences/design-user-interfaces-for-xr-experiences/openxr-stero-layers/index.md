# OpenXR立体图层

> 路径：虚幻引擎5.7文档 / 分享和发布项目 / XR开发 / 为XR体验设计UI / OpenXR立体图层

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/openxr-stero-layers-in-unreal-engine

在为头戴式显示设备（HMD）开发内容时，OpenXR立体图层（OpenXR Stereo Layers）允许你单独将某张纹理重新投射到某个单独的渲染通道中。这使得HMD中的UI内容可以单独渲染，从而不必受某些设置（比如后期处理、抗锯齿）的影响。

- [OpenXR立体图层概述](openxr-stero-layers-overview/index.md) - 让纹理在一个单独的通道中渲染到HMD显示设备上，从而避免纹理受到后期处理效果的影响。

- [OpenXR立体图层快速入门](openxr-stereo-layers-quick-start/index.md) - 了解如何在项目中添加OpenXR立体图层内容。

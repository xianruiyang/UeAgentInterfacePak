# 支持的混合现实视频设备

> 路径：虚幻引擎5.7文档 / 使用媒体 / 媒体集成 / 混合现实捕获 / 支持的混合现实视频设备

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/supported-video-devices-for-mixed-reality-capture-in-unreal-engine

我们已针对数量有限的视频捕捉设备测试了混合现实捕捉（MRC）框架。这并不是说其他视频捕捉设备无法正常工作，无论如何，以下是我们Epic Games已经进行过测试的设备列表。

**网络摄像头**

- Logitech C920
- Logitech C930e

**USB采集棒**

- Magewell USB Capture HDMI Gen 2

  ¹

¹ 尽管未经过测试，但是其他Magewell USB采集产品也能够与MRC兼容，例如他们用于4K的[Plus型号](http://www.magewell.com/usb-capture-hdmi-4k-plus)和他们用于播放硬件的SDI采集棒。

高级用户可以编写媒体框架插件来支持他们自己的视频捕捉设备。

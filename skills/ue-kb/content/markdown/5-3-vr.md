## 摘要

在发现 VR 编辑器模式并感到非常兴奋之后，我很失望地发现它在 5.3 版本的某个地方消失了（在虚拟制作模板之外）。在官方文档碰壁并且在网上找不到解决方案后，我决定窥探默认的虚拟制作项目文件，看看是否可以找到神奇的开关来在现有的 VR 模板项目（或任何其他项目）中启用该模式。找到了。

## 中文整理

### 步骤：

### 1. 使用 Visual Studio 打开您的projectname.uproject 文件（unrealprojects/projectname）。

### 2. 将以下内容复制并粘贴到文件中：

```cpp
{
"Name": "VirtualScouting",
"Enabled": true,
"SupportedTargetPlatforms": [
"Win64",
"Linux"
]
},
{
“Name”: “OpenXR”,
```

### 3. 打开您的项目，您应该可以看到“切换 VR”按钮。

### 4. 按照此处的说明进行操作，但步骤 7 和 9 除外，这两个步骤与当前设置屏幕不对应。

- [激活虚拟侦察工具](https://docs.unrealengine.com/5.3/en-US/activating-the-virtual-scouting-tools)

### 5. 在项目设置 - 引擎 - 渲染 - 后处理下，将“在后处理中启用 alpha 通道支持（实验）”设置为“禁用”。

![教程图片](assets/unreal-engine-enabling-vr-editor-mode-in-5-3-in-any-project/image-01.jpg)

6. 在“项目设置”-“插件”-“OpenXR 输入”-“增强输入”下，将“XR 的可映射输入配置”设置为“无”（我想每次您想要测试 VR 项目的“游戏”部分时都必须恢复该设置）。

### 7. 连接耳机并按下 VR 模式按钮。

设置

在创建这种粒子特效之前，你需要一个骨骼网格模型作为轮廓的基础。这里，我使用的是我制作的美少女战士模型的副本。

骨骼网格体应该作为一个 单独的对象 存在，除非你希望发射器仅从网格体的特定部分发射能量。如果你的对象是静态网格体或由多个网格体组成，你可以通过在大纲视图中选择所有网格体，然后依次选择 “文件”>“导出所选内容”，创建一个新的 .fbx 文件，再将其作为骨骼网格体重新导入到你的项目中，从而将它们转换为单个骨骼网格体。

现在你可以创建尼亚加拉发射器了。我建议选择 “新建发射器” > “喷泉” 作为此效果的起点。

## 第0部分 - 尼亚加拉发射器基础知识

如果您不熟悉 Niagara，或者只接触过 Unity 等其他粒子系统，那么资源编辑器窗口中的选项可能会让您感到不知所措。简单来说，Niagara 粒子系统并非提供一系列可供调整的参数，而是使用独立的“模块”来定义发射器的特定行为。添加到 “粒子生成 ”中的模块和参数会冲击效果粒子在初始渲染时的行为，而添加到 “粒子更新” 中的模块则会冲击效果粒子在其生命周期内的行为。 Each module accepts its own parameters,

每个模块都接受自己的参数，而参数本身也可以使用修饰符来冲击效果其行为。例如，一个参数可能接受一个浮点值，但 “随机范围浮点数” 修饰符允许该浮点参数在每个粒子的指定范围内随机化。

## 部分 1 - Particle design

## 第一部分 - 粒子设计

我们可以先调整粒子的视觉效果和默认参数，使其成为我们特效的基础。我调整了 “初始化粒子” 模块中的默认设置，使其具有固定的生命周期、特定的颜色范围和统一的大小。

您可以在粒子生成或粒子更新中添加或移除其他模块，以达到所需效果。例如，我移除了 重力、 拖拽 和 缩放颜色 模块。 I'm using the default sprite material for this effect,

我使用的是默认的精灵材质来实现这个效果，但如果你想使用自定义的精灵形状，我建议你复制默认材质，并将 alpha 值替换为你的纹理。

## 部分 2 - Mesh Emission

## 第二部分 - 网格发射

实现此效果的关键模块是 “初始化网格再现精灵” 模块。将其添加到发射器的“粒子生成”部分，并将之前创建的骨骼网格分配给 “预览网格” 部分。此模块会随机选择网格上的一个三角形作为粒子发射位置。

如果您的效果没有为网格创建明显的轮廓，请尝试调整 粒子缩放 参数和 生成速率 模块的值。

## 部分 3 - Climbing Effect

## 第三部分——攀升效应

现在你已经有了粒子系统的轮廓遮罩，接下来需要添加攀爬效果，让轮廓向上移动，覆盖网格的形状！为此，我们将使用“粒子生成”部分的 “杀死粒子” 模块。 Initially Kill Particles simply accepts a boolean parameter to kill all particles in the emitter. However,

最初， “杀死粒子”函数 只接受一个布尔参数，用于杀死发射器中的所有粒子。但是，我们可以使用动态输入修改器 “通过浮点数比较设置布尔值” 来赋予它一些独特的行为，例如只杀死场景中的特定粒子。

在浮点数比较的前半部分，我们需要粒子的位置信息，具体来说，对于垂直攀爬效果，我们需要粒子的 Z 轴位置。为了获取这个信息，我们可以使用“ 从矢量生成浮点数” 修改器，并结合 “初始化网格再现精灵” 的 “位置 ”输出和 Z 通道。这样我们就可以根据粒子生成时的 Z 轴位置来销毁它们。给第二个浮点数赋值后，你就能看到这种方法的效果了。

## 第四部分 - 使用发射器

现在你已经完成了特效，可以通过右键单击内容抽屉中的发射器并选择 “创建尼亚加拉系统” 将其添加到场景中。然后你可以将该系统拖动到场景中的任何位置！如果你想让它与场景中的原始网格重叠，只需调整变换使其与原始对象的位置匹配即可！

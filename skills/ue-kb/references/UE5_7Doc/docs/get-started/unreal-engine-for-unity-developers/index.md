# 为Unity开发者准备的虚幻引擎指南

> 路径：虚幻引擎5.7文档 / 入门指南 / 为Unity开发者准备的虚幻引擎指南

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/unreal-engine-for-unity-developers

如果你想从Unity转到虚幻引擎，本章节将提供如下入门知识：

- 概述Unity和虚幻引擎之间的异同。
- 说明特定的Unity术语和虚幻引擎术语的对应关系，帮助你将Unity的知识转化为虚幻引擎的知识。
- 了解蓝图和C++之间的区别，让你能够根据项目需求选择何时使用蓝图或C++。
- 学习如何将Unity资产导入到虚幻引擎中。
- 了解虚幻引擎的渲染技术。

如果你以前从未使用过虚幻引擎，请先阅读[Unity转虚幻引擎概述](unity-to-unreal-engine-overview/index.md)，该页面介绍了与Unity关键术语和概念相对应的虚幻引擎术语和概念。

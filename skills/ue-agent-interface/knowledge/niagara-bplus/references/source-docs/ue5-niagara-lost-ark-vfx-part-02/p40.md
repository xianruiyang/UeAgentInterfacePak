### 00:00:03-00:02:53 材质、生命周期、速度

- 本段定位：材质、生命周期、速度。
- 知识点：线性的感觉 如此大小增加时 这种S字感觉了纹理 中火的这种感觉适当出现 我觉得适当降低外国的价格比较好 边缘添加降为0 功率保持为0 刚才的边缘添加太强了。
- 知识点：这种纹理似乎没能更好地展现 刚才改变颜色后 火焰心中出现的颜色 最后火焰逐渐减弱时 饱和度上升的感觉可以一起带走 从这个视角看会更真实。
- 知识点：可以给出更散的火焰感觉 这样品牌化会很好 只有这个稍显空旷的感觉 这个可以放入地也可以不放 想以水油的感觉来使用 材质将会使用相同的材质。
- 知识点：在大小或这些排列上 稍作不同会更好 动态参数也最好复制成同样的感觉 这种布局感觉适当看一下 数量保持8个不变 生命周期感觉适当快一点跟快消失。
- 知识点：用绥纪移植均匀 适当短一点 没有打算让它太长太突出 所以形状位置大概在50左右 把速度适当呈斜线的感觉。

- 复现要点：材质侧要核对 Blend Mode、Opacity/Alpha、Emissive、UV/Panner、Depth Fade 或 SubUV/Flipbook 的真实连接。
- 复现要点：User Parameter 与 Dynamic Material Parameter 负责跨 Niagara、蓝图和材质传值，命名和类型必须稳定。

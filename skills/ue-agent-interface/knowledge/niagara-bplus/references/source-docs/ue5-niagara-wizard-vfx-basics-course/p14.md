### 00:00:00-00:04:54 Niagara、粒子、网格

- 本段定位：Niagara、粒子、网格。
- 知识点：好,我们开始下一个效果 我新建了一个火焰漩涡 等级是七级 还搭了个简单场景 跟火环用的差不多 背景就放了三块Quixel石头 地上摆了几棵树。
- 知识点：都是Quixel的 这些不是必须的 对吧,场景怎么搭都行 所以我们就用火环的Niagara设置。
- 知识点：当火焰漩涡的基础 这样就不必从零开始重做所有内容了 进入VFX文件夹 找到NS火环 按Ctrl加D复制 命名为NS瞎化线火焰漩涡 拖入材质或模块输入场景。
- 知识点：按Ctrl加E打开生神速率设置 设为5000 接下来是生命周期 我设最小值0.5 然后需要让偶尔来一波更长的火焰 所以本段再随机一次最大值。
- 知识点：这是个实用小窍门 能让Niagara输出随机的数据 第二个最小值 我设0.75 最大值留1 可以删掉网格位置 换成形状位置 因为得用横面 对吧。
- 知识点：使用横面作为形状记元 主半径设为250 内半径及环密管状部分的半径15 可以关闭重力影响 火焰持续太久 来调整流体源属性 密度设为0.2。
- 知识点：烟雾浓度稍低 发散度太高 火焰膨胀得太过分了 下限设成0就行 最大值也再随机一次 随机范围设为0 1到4之间 也就是说有些粒子会突然像爆炸一样喷出火焰。
- 复现要点：Initialize Particle 通常负责 Lifetime、Color、Position、Sprite Size 或 Mesh Scale 等基础属性。
- 复现要点：材质侧要核对 Blend Mode、Opacity/Alpha、Emissive、UV/Panner、Depth Fade 或 SubUV/Flipbook 的真实连接。
- 核对对象：`Niagara`、`材质`、`粒子`、`序列`、`生命周期`、`速度`、`烟雾`、`火焰`。

### S01 00:00:13

这张补充图提供的是 `NS_zombie` 流体发射器的力场参数细节，重点是两组湍流参数如何被压低到更适合僵尸燃烧的级别，避免火焰像海啸一样翻卷过头

- 当前编辑对象
  当前选中的是 `Grid3D_Gas_Master_Emitter`
  右侧 `Emitter Summary` 切在 `Forces` 标签
  左侧预览仍是竖向的人形燃烧火焰
  说明这些力场参数正在直接作用于僵尸燃烧用的体积火焰
- 已确认参数
  `Calculate Vorticity Confinement = True`
  `Vorticity = 2.5`
  `Vorticity Velocity Falloff = 0.0`
  `Turbulence 1`
  `Calculate Turbulence = True`
  `Turbulence Frequency = 0.025`
  `Turbulence Speed = 2.0`
  `Mask Channel = Density`
  `Mask Type = Band`
  `Mask Range = 0.0 - 99999.0`
  `Turbulence Gain = 600.0`
  `Velocity Based Turbulence Gain = 0.0`
  `Turbulence 2`
  `Calculate Turbulence = True`
  `Turbulence Frequency = 0.01`
  `Turbulence Speed = 1.0`
  `Mask Channel = Density`
  `Mask Type = Band`
  `Mask Range = 0.0 - 99999.0`
  `Turbulence Gain = 500.0`
  `Velocity Based Turbulence Gain = 0.0`
- 复现含义
  正文提到“湍流强度太大了，对吧，像海啸一样，把湍流 2 调成 0.01，第一个参数也调一下”
  这张图正是那一步的补证
  通过把两组湍流频率压低到 `0.025` 与 `0.01`
  可以让僵尸身上的火焰仍然有翻卷感，但不至于被流体噪声拉得过于夸张

## 几何体缓存

### 几何体缓存流送器

| **设置** | **说明** |
| --- | --- |
| **预读缓冲区（以秒为单位）（Look-Ahead Buffer (in seconds)）** | 要提前（按流送）流送的动画数量（以秒为单位）。 |
| **允许的最大内存（以MB为单位）（Maximum Memory Allowed (in MB)）** | 内存中允许的流送数据的最大总数量（对于所有流送）。 |

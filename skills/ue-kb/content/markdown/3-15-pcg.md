# 3.15分钟真实的战区!程序内容生成PCG在虚幻引擎

## 知识目标

- 用 PCG 快速搭建一个雨天、烧毁森林、弹坑和火焰组成的战区环境。
- 把环境制作拆成天气氛围、Landscape/材质、PCG 植被与地表物、弹坑和 Niagara 火焰几个可复现模块。

## 可复现主流程

1. 先建立场景氛围：使用 Ultra Dynamic Sky / Ultra Dynamic Weather 设置雨、雾和低饱和照明。
2. 创建 Landscape，并使用 Quixel/Megascans 的烧毁森林地表材质和资产作为环境基底。
3. 启用 PCG 插件，创建 PCG Graph 与 PCG Volume，用 Landscape 输入接 Surface Sampler 生成点。
4. 用 Static Mesh Spawner 分层生成草、石块、烧毁树木和地表碎片。
5. 用 Density Noise、Density Filter、Seed、Points Per Square Meter 和 Bounds Modifier 控制自然分布与碰撞范围。
6. 添加 crater/弹坑资产，并通过 Transform Points 调整位置、缩放和旋转。
7. 在弹坑或指定点上 Spawn Niagara Actor，生成火焰、烟雾等战区视觉细节。

## 操作步骤与要点

### 天气和地表基底

- 先用天气、雾和地表材质确定战区气氛，再进入 PCG 细节生成。
- Quixel/Megascans 烧毁森林资产提供了地表、树木和碎片的主要素材来源。

- 不同资产类型应拆成不同分支，分别设置 Density Filter、Bounds Modifier 和 Transform Points。

## 复现检查清单

- 天气、材质、PCG 资产三者要先统一风格，否则生成数量再多也会显得杂乱。
- 每新增一种资产先单独 Debug 点，再接 Static Mesh Spawner。
- 树木、弹坑和火焰不要共用同一套密度参数。
- Niagara Actor 生成后要检查粒子朝向、地面穿插和性能开销。

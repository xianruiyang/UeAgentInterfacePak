# 创建物理材质

> 路径：虚幻引擎5.7文档 / Gameplay系统 / 物理 / 物理材质 / 物理材质教程 / 创建物理材质

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/create-a-physical-material-in-unreal-engine

1. 在内容浏览器中，点击 **添加/导入（Add/Import）** -> **物理（Physics）** -> **物理材质（Physical Material）**，或在 **内容浏览器** 中右键点击，然后点击 **物理（Physics）** -> **物理材质（Physical Material）**。

   ![Create Physical Material](../../../../../../assets/images/e1/e1de7510ec616bad64096abc2e8bc2156c8a4be5ce2558dfab2cfc0ed7b1f49e.jpg)
2. 选择 **物理材质类（Physical Material Class）**。

   ![Select the Physical Material Class](../../../../../../assets/images/e9/e95c6a326ccae96441e80289d5a6abd20f1ec0b469d53a46b7ffe76bb5a87fe1.png)
3. **双击** 新物理材质以编辑其属性。

   ![Double-click the new Physical Material to open it](../../../../../../assets/images/60/6019f746ef604abd5601e8547cb3d14c3828fe29177d791de36c4a37954d67fd.jpg)
4. 调整 **属性**。

   ![Adjust the Properties](../../../../../../assets/images/59/59ff552ef78adb53ea69439c30e9fe6212ac8977736fed8d98c594ee2fba9799.png)
5. 点击 **保存** 。

请参见[**物理材质参考**](../../physical-materials-reference/index.md)，了解物理材质属性的相关信息。

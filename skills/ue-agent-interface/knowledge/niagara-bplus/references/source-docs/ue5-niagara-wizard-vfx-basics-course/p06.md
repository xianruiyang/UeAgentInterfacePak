### S01 00:02:58

这张补充图展示的是 `DefaultRibbonMaterial2` 的材质图，核心目标是让丝带闪电的两端都出现透明渐变，而不是只在一侧淡出

- 节点定义集
  `Particle Color`
  用粒子颜色同时驱动发光与透明
  `TextureCoordinate`
  左侧节点仅露出末尾，可确认其输出接到 `Mask (R)`，语义是取 UV 坐标
  `Mask (R)`
  从纹理坐标中提取 `R` 通道，得到沿丝带长度方向的 0 到 1 渐变
  `OneMinus`
  对 `Mask (R)` 结果做反相，得到反向渐变
  `Multiply A`
  用 `Particle Color.A` 与反向渐变相乘
  `Multiply B`
  再把上一步结果与正向渐变相乘，形成“两端低、中间高”的透明遮罩
  `DefaultRibbonMaterial2`
  材质输出节点
- 连线集
  `Particle Color.RGB -> DefaultRibbonMaterial2.Emissive Color`
  `TextureCoordinate -> Mask (R)`
  `Mask (R) -> OneMinus`
  `Particle Color.A -> Multiply A.A`
  `OneMinus -> Multiply A.B`
  `Multiply A -> Multiply B.A`
  `Mask (R) -> Multiply B.B`
  `Multiply B -> DefaultRibbonMaterial2.Opacity`
- 设置/参数
  `TextureCoordinate` 可见 `Coordinate Index = 0`
  `Mask (R)` 只取红通道，也就是 U 方向渐变
  `OneMinus` 常量显示为 `1 - X`
  当前选中的乘法节点在左下 `Details` 里显示
  `Const A = 0.0`
  `Const B = 1.0`
- 输出/预览

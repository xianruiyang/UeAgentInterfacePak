## 关卡Sequencer

### 轨道

| **设置** | **说明** |
| --- | --- |
| **轨道设置（Tracks Settings）** | 指定将为其自动创建电影场景轨道的类属性。 |

### 播放

| **设置** | **说明** |
| --- | --- |
| **自动绑定到PIE（Auto Bind to PIE）** | 指定是否自动将活动Sequencer UI绑定到PIE世界。 |
| **自动绑定到模拟（Auto Bind to Simulate）** | 指定是否自动将活动Sequencer UI绑定到模拟世界。 |

# Android单实例服务

> 路径：虚幻引擎5.7文档 / 移动端开发 / 汽车HMI开发 / Android单实例服务

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/android-single-instance-service-in-unreal-engine

虚幻引擎的**Android单实例服务**是一款插件，可将虚幻引擎项目打包为适用于Android设备的单实例服务。 虚幻引擎运行时会在启动时初始化，然后单独的虚幻引擎应用程序会被附加到该进程，从而减少双方共享的内存占用和启动时间。

- [设置Android单实例服务](setting-up-android-single-instance-service/index.md) - 了解如何设置Android单实例服务（ASIS），以及如何将项目作为Android应用程序进行创建、打包和运行。

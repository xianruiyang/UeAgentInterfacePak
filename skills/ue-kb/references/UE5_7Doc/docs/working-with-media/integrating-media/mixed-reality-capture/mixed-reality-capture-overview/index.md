# 混合现实捕捉概述

> 路径：虚幻引擎5.7文档 / 使用媒体 / 媒体集成 / 混合现实捕获 / 混合现实捕捉概述

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/mixed-reality-capture-overview-for-unreal-engine

混合现实捕捉（MRC）框架使用户可以更轻松地将真实玩家合成到虚拟游戏空间中，使监视XR体验变得更加真实。

混合现实捕捉支持具有三个组成部分：视频输入、校准和游戏内合成。我们支持一系列的[网络摄像头和HDMI捕捉设备](../supported-video-devices-for-mixed-reality-capture/index.md)，使您能够从各种各样的源将真实世界绿幕视频拉取到虚幻引擎中。如果具有单独的追踪设备，混合现实捕捉可以将摄像机位置与游戏内摄像机进行匹配，以使镜头更加动态和有趣。设置和校准通过独立的校准设备进行。设置并校准好摄制位置后，可以在虚幻应用程序中重复使用这些校准设置。

虽然功能支持已进入测试阶段，我们仍然期待收到反馈，以帮助我们持续改善该框架。

遵循[混合现实快速入门](../mixed-reality-capture-quick-start/index.md)中的步骤开始使用混合现实捕捉。

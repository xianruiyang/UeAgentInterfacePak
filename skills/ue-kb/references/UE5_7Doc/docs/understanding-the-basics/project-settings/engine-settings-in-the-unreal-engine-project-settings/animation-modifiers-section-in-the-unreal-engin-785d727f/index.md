## 动画修饰符

### 修饰符

| **分段** | **说明** |
| --- | --- |
| **默认动画修饰符（Default Animation Modifiers）** | 每当导入新的动画序列时要添加的一组动画修饰符。 |
| **在导入时应用动画修饰符（Apply Animation Modifiers on Import）** | 定义是否在导入或重新导入后应用动画修饰符。 |

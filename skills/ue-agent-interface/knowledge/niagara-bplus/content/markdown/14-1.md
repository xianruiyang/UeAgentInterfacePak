### 00:00:00-00:04:55 Niagara、Module、Spawn

- 本段定位：Niagara、Module、Spawn。
- 知识点：火焰或爆炸需要拆分亮核、烟雾、余烬和冲击层，再用颜色与透明度曲线统一节奏。

- 知识点：本段围绕 `Niagara` 进行设置，需结合关键画面核对真实节点和参数。
- 知识点：Niagara Fluids 需要重点检查 Gas/Fluid Emitter、网格分辨率、Bounds 和缓存/实时预览状态。
- 知识点：烟雾效果通常依赖较长 Lifetime、透明度衰减、噪声扰动和柔和的材质混合。；火焰或爆炸需要拆分亮核、烟雾、余烬和冲击层，再用颜色与透明度曲线统一节奏。
- 知识点：烟雾效果通常依赖较长 Lifetime、透明度衰减、噪声扰动和柔和的材质混合。
- 知识点：本段围绕 `Particle` 进行设置，需结合关键画面核对真实节点和参数。
- 复现要点：Spawn Rate、Burst 或 Spawn Per Unit 决定生成节奏，需要和 Lifetime 配合控制屏幕密度。
- 复现要点：Initialize Particle 通常负责 Lifetime、Color、Position、Sprite Size 或 Mesh Scale 等基础属性。
- 复现要点：材质侧要核对 Blend Mode、Opacity/Alpha、Emissive、UV/Panner、Depth Fade 或 SubUV/Flipbook 的真实连接。
- 复现要点：碰撞、GPU/CPU Sim、Bounds 和 Local Space 会影响可见性、性能和触发精度，复现时要单独检查。

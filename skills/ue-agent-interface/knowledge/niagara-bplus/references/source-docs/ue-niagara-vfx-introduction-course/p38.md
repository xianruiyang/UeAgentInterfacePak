### 00:00:05-00:04:59 Niagara、System、Renderer

- 本段定位：Niagara、System、Renderer。
- 知识点：我们一直通过托放来生成我们的VFX,Niagara系统,到我们的关卡中。
- 知识点：但通常,如果这是他们想要在游戏中使用的效果,简单地拖入材质或模块输入一个Niagara系统是行不通的。
- 知识点：如果你还记得我们的Ribbon Renderer,在这个BP第三人称角色上添加了一个Niagara组件。
- 知识点：这是在游戏中生成VFX的一种方法,是使用。
- 知识点：这个静态函数,叫做Spawn System and Location,生成系统。
- 知识点：并且基于这两种不同的生成类型,对于他们相应的Niagara发射器也有不同的要求。
- 知识点：否则,如果在关卡中生成它,那么Niagara系统将始终存在。
- 复现要点：Spawn Rate、Burst 或 Spawn Per Unit 决定生成节奏，需要和 Lifetime 配合控制屏幕密度。
- 复现要点：Renderer 决定最终可见形态；Sprite、Mesh、Ribbon 的材质、朝向、排序和尺寸语义不同。
- 复现要点：材质侧要核对 Blend Mode、Opacity/Alpha、Emissive、UV/Panner、Depth Fade 或 SubUV/Flipbook 的真实连接。
- 复现要点：蓝图、Sequencer 或 Montage 触发 Niagara 时，要确认生成位置、生命周期和销毁时机。
- 核对对象：`Niagara`、`Spawn`、`Ribbon Renderer`、`Renderer`、`材质`、`发射器`、`系统`、`蓝图`。

## 复现检查

- 先单独验证 Emitter 的 Spawn、Lifetime、Renderer 和材质，再叠加到完整 Niagara System。
- 节点名、模块名和参数值以关键截图中的实际 UI 为准；OCR 只用于辅助定位。
- 涉及透明、Additive、SubUV、Flipbook 或 Depth Fade 时，重点检查材质混合模式、Alpha/Opacity 与 Emissive 强度。
- 涉及蓝图、Sequencer 或 Montage 时，确认触发位置、触发时机、生命周期和销毁逻辑。

> | ID | 节点/端口 | 读到的信息 |
> |---|---|---|
> | N01 | `TexCoord[0]` | `Coordinate Index=0`；输出分叉到 N03.`Coordinate`、N04.`Coordinate`，并向下接入局部可见的 Add 分支 |

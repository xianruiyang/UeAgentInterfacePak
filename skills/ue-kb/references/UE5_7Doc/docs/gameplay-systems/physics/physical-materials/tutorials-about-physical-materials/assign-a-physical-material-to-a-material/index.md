# 将物理材质指定给材质

> 路径：虚幻引擎5.7文档 / Gameplay系统 / 物理 / 物理材质 / 物理材质教程 / 将物理材质指定给材质

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/assign-a-physical-material-to-a-material-in-unreal-engine

1. 打开或新建一个 **材质**。

   ![Open or create a new Material](../../../../../../assets/images/da/dab5bce5bf89c661558ee0f55aac4213aa34b23e3841b7342cfdd8808602c572.png)
2. 在 **材质蓝图** 中，选中主材质节点。

   ![Select the main material node](../../../../../../assets/images/23/2322524f67f1cb7c54858847c61243e77ceb1e68c47611dc65e8daca6e6105a6.jpg)
3. 在 **细节** 面板中，使用物理材质下拉菜单，选择或创建一个物理材质。

   ![Use the Physical Material dropdown to select or create a Physical Material](../../../../../../assets/images/d3/d3d6daa4c9c42a3b65ffd3c7b8b4560e80b4bf20105bdd597834b0f96cb8d243.jpg)
4. 单击 **保存**。

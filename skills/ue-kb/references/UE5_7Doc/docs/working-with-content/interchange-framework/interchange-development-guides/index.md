# 交换开发指南

> 路径：虚幻引擎5.7文档 / 管理内容 / 交换框架 / 交换开发指南

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/interchange-development-guides

**交换框架（Interchange Framework）** 是一个灵活的导入框架，使用可自定义的管线从各种文件类型导入资产数据。本小节包含开发指南和特定于文件的参考文档，可帮助你为项目定制导入过程。

- [交换导入参考](interchange-import-reference/index.md) - 该参考指南概述了使用交换导入内容时可能用到的接口和选项。

- [交换MaterialX参考](interchange-materialx-reference/index.md) - 关于使用交换框架中的MaterialX格式的参考指南。

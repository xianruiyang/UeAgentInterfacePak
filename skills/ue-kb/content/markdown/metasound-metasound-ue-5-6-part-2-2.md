### 设置通知以广播旋钮值更改

我们的旋钮的小部件蓝图需要的最后一件事是通知绑定源值已更改的事件。为此，我们可以使用旋钮小部件的“旋钮值更改”事件来调用“广播字段值更改”函数。您可能会注意到有两个名为“广播字段值已更改”的函数。其中任何一个都可以工作。一个有一个对象输入参数，您可以将对 self 的引用传递到其中，另一个有一个目标输入参数，该参数已默认为 self。
### 设置视图模型绑定

我们已经完成了蓝图！现在剩下的就是使用设计器视图中的视图绑定面板设置视图模型绑定。
### 将视图模型绑定到旋钮小部件

取消选择任何选定的小部件，然后单击“视图绑定”窗格中的“添加小部件”按钮。如果您选择了一个小部件，“添加小部件”按钮将更改为“添加小部件[选定的小部件]”，这可以更轻松地在其他场景中设置绑定。单击左侧标记为“未选择字段”的框，然后使用搜索框找到“设置旋钮值”，这是我们刚刚添加到小部件中的功能。选择该函数，然后单击“选择”按钮。我们刚刚设置了绑定的目的地。接下来，我们需要设置绑定的源。首先单击右侧标记为“未选择字段”的框，然后单击“MetaSoundInputEditorViewModel”。右侧的面板将显示所有可用的绑定，但我们只需要名为 Literal 的绑定。选择“文字”，然后单击“选择”按钮。现在，当在 MetaSound 编辑器中对 MetaSound 资源进行更改时，我们的旋钮将收到更新。
### 将旋钮绑定到视图模型

反向设置非常相似。单击选择了 MetaSoundFloatEditor 的字段旁边未标记的加号，可快速将新绑定添加到小部件。这次，我们希望将绑定的目标设置为 MetaSound 输入编辑器视图模型上的 Literal 属性。您可以通过展开 MetaSoundInputEditorViewModel 的属性在右侧窗格中找到它。对于绑定源，我们将使用我们创建的另一个函数，Get Knob Value as Literal。
### 绑定文本小部件

最后，让我们确保旋钮的文本标签分别绑定到输入名称和旋钮值。通过单击选择顶部文本小部件，然后单击“视图绑定”面板上的“添加小部件文本”按钮。将左侧的绑定目标设置为文本小部件的 Text 属性。这次我们需要使用转换函数，因为 Text 属性需要 Text 数据类型，而我们的 Input Name 属性具有 Name 数据类型。在右侧的绑定源字段中，找到“转换函数”类别下的“转文本（名称）”函数。您可以通过在所属小部件中创建接受多个输入的自定义转换函数或将其创建为蓝图函数库内的静态函数来创建接受多个输入的自定义转换函数。它们仍然必须返回单个值，但允许绑定多个输入参数。绑定下方将出现一个新字段，允许我们设置转换函数的输入参数。单击该字段旁边的链接图标，然后将绑定设置为 MetaSoundInputEditorViewModel 的“输入名称”属性。我们可以以完全相同的方式设置值文本小部件，但这次我们将绑定源设置为 MetaSoundInputEditorViewModel 的 Get Value as Text 函数，这允许我们显示当前值。编译并保存小部件，因为现在我们准备将其添加到我们的主预设编辑器小部件中！
### 完成 MetaSound Preset 小部件

让我们回到主要的 MetaSound 预设小部件，这样我们就可以通过添加新创建的旋钮小部件来完成。
### 添加 MetaSoundFloatEditor 旋钮小部件

在 Palette 面板中，找到我们刚刚完成创建的旋钮小部件，并将一个或两个实例添加到 StackBox 根小部件。为您想要编辑的任意数量的浮点输入添加一个。对于这个例子我只需要两个。
### 将输入视图模型绑定到每个旋钮

和以前一样，通过将绑定目标设置为旋钮小部件的设置视图模型函数，为每个旋钮小部件创建绑定。使用“按名称查找输入视图模型”转换函数来设置绑定源。将 MetaSound 输入视图模型输入绑定到主小部件的 MetaSoundEditorViewModel 中的获取输入视图模型函数。这是完成后的样子。
### 享受使用新预设编辑器小部件的乐趣！

打开您的 MetaSound 预设并转到预设小部件选项卡。您的小部件现在应该能够控制默认输入参数值，并在以标准方式修改默认值时接收更新。在本教程中，我们介绍了 MetaSound 视图模型的基础知识，但创建其他类型的 MetaSound 编辑器实用程序还有更大的潜力。请继续关注更多更新！

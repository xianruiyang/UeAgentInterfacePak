这一张开始搭建翅膀材质的纹理平移与扰动部分。当前可确认的节点定义与连线如下：

- `TexCoord[0]`：
  - `Coordinate Index = 0`
  - `UTiling = 0.3`
  - `VTiling = 0.75`
- 一个常量 `0` 与另一条未完整露出的输入一起进入 `Append`，用于组装二维偏移向量。

- 上方 `Texture Sample` 采样的是一张蓝紫色法线/扰动纹理；其输出经过 `Mask (RG)` 只保留红绿两个通道，再进入 `Multiply (0.02)`，把扰动幅度压低。
- 右侧另外两张 `Texture Sample` 纹理已经摆入图中，其中一张是细长拖尾状的白色纹理，另一张是更块状的亮纹理，作为后续翅膀形状和细节贴图来源。

这一步的作用是先建立“基础 UV + 小幅偏移噪声”的采样方式。讲师通过低倍率的 `TexCoord` 和极小的 `RG * 0.02` 扰动，为后续翅膀表面增加轻微流动感，避免纹理静止贴在网格上显得生硬。
这一张把翅膀纹理层的亮度塑形网络补全到了可复建的程度。可见结构如下：

- 上方路径：
  - 前一张图得到的扰动值 `Multiply (0.02)` 输出，接入一个 `Add`，与另一条基础 UV/偏移输入叠加。
  - `Add` 输出进入一张细长白色拖尾纹理的 `Texture Sample` 的 `UVs`。
  - 该纹理采样结果进入 `Power (X,1.5)`。
  - `Power` 输出再进入 `Multiply (5)`，把亮度增强 5 倍。
- 下方路径：
  - 另一张亮纹理 `Texture Sample` 也进入一组 `Power (X,1.5)`。
  - 其输出进入 `Multiply (1)`，当前保留原倍率。
- 两路结果最后进入右侧 `Add`，合成为一张更复杂的发光遮罩。
- 上方还新增了一组 `TexCoord[0] -> Mask (G)`，说明讲师开始单独提取 UV 的 `V` 通道，为后续沿纵向做平移或遮罩控制做准备。

这一步的作用是把两张不同特征的灰度/亮度纹理叠加起来：一张负责细长的拖尾流动感，另一张负责补足大块亮部轮廓；先用 `Power(1.5)` 压缩中灰、强化亮部，再用倍率放大，得到更适合翅膀能量边缘的发光分布。

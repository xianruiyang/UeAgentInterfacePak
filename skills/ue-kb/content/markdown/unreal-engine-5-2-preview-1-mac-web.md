## 中文整理

### 概览

*本文由 Davin F 撰写。* 在 Mac 上的编辑器中使用嵌入式 Web 浏览器（例如 Quixel Bridge）时，浏览器中的菜单快捷方式和文本字段会发生冲突。对接这些网页视图会使问题更加频繁，因此建议将它们保留为浮动状态。如果遇到问题，可以使用右键单击将文本粘贴到字段中来解决崩溃问题，或者可以从不使用 Command 键的常用视口命令中取消菜单快捷方式的绑定。在[知识库！](https://forums.unrealengine.com/docs) 中获取更多答案

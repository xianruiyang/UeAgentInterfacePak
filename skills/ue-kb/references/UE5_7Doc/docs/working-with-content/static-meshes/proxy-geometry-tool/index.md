# 代理几何工具

> 路径：虚幻引擎5.7文档 / 管理内容 / 静态网格体 / 代理几何工具

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/proxy-geometry-tool-in-unreal-engine

代理几何工具集是一种提高您的虚幻引擎4(UE4)项目性能，同时保持您项目的视觉质量不受影响的工具。

> [!NOTE]
> 代理几何工具目前只支持使用Microsoft Windows的PC。今后将增加对Mac和Linux的支持。

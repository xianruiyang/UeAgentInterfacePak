# Horde配置

> 路径：虚幻引擎5.7文档 / 建立你的开发流程 / Horde / Horde配置

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/horde-configuration-for-unreal-engine

本节旨在介绍如何操作和管理Horde系统，并分享了我们在为Epic团队提供支持的过程中所积累的一些最佳实践。

## 一般信息

- 配置指南

  ：了解如何配置Horde，如何将配置数据存储在版本控制系统中，以及如何设置模式服务器。
- 权限

  ：了解如何使用Horde权限模型。

## 资源

- 代理

  ：配置链接到Horde的工作站，用于CI和远程执行工作区。
- 设备

  ：将移动设备和主机开发套件添加为共享资源。
- 保密

  ：允许Horde管理对保密值的访问。
- 存储

  ：为Horde设置不同的存储后端。

## 功能

- 自动化编译
- 自动化中心
- UnrealGameSync元数据服务器

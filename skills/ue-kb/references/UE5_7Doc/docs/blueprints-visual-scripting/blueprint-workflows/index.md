# 蓝图工作流程

> 路径：虚幻引擎5.7文档 / 蓝图可视化脚本 / 蓝图工作流程

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/blueprint-workflows-in-unreal-engine

如果你刚接触虚幻引擎的[蓝图可视化脚本](../index.md)，阅读本蓝图教程将大有裨益。本教程提供了关于蓝图使用核心概念的信息，包括创建蓝图、添加和连接节点、创建变量以及下表所示的其他内容。

在熟悉并了解蓝图的核心要素后，可在[Gameplay系统](../../gameplay-systems/index.md)中查看"Gameplay导向蓝图教程"。该文将对Gameplay相关要素进行说明，如生成/摧毁Actor、（摧毁后）重新生成、使用计时器等。

## 初级

- [创建宏](making-macros/index.md) - 创建一个宏用来检查玩家是否有足够能量来跳跃。
- [创建函数](creating-functions/index.md) - 创建一个按键时显示文本的函数。
- [Set and Get an Actor Reference](set-and-get-an-actor-reference/index.md) - Use an actor reference to move actors around in a level.
- [放置节点](placing-nodes/index.md) - 说明添加节点到蓝图的方法。
- [折叠图表](collapsing-graphs/index.md) - 将节点折叠为新图表、函数或宏。
- [连接节点](connecting-nodes/index.md) - 蓝图中节点连接方式的范例。
- [蓝图调试示例](blueprint-debugging-example/index.md) - 使用断点暂停执行，以检查图表及变量值。

# 纹理流送

> 路径：虚幻引擎5.7文档 / 设计视觉、渲染和图形效果 / 优化和调试实时渲染项目 / 纹理流送

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/texture-streaming-in-unreal-engine

纹理流送系统，又称纹理流送器，是引擎中负责提高和降低每个纹理分辨率的部分。这能让你在拥有出色的视觉效果的同时，可以有效管理内存。

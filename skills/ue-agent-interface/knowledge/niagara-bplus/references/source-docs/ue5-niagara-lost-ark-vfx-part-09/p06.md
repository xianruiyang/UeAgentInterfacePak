- `Grain Offset = 0.03`
- `Grain Offset Seed = 0`

### S03 00:11:21

这张补充图为 `S03` 段的模拟测试提供了更清晰的 graph+结果同屏证据。左侧视口中，破碎板已经被蓝色球体撞散成一团碎块，较大的彩色块体和较小的碎片同时散落在地面上方，说明当前 Bullet 求解器不只是完成了“是否会碎”的测试，而是已经能稳定地处理碎块碰撞、分离和落体运动。

当前可可靠确认的相关结构为：

- `rbdmaterialfracture1` 的多路输出接入 `rbdbulletsolver1`
- `sphere1` 作为独立碰撞体与 `rbdbulletsolver1` 关联
- `explodedview1` 仍保留在混凝土分支一侧
- 玻璃分支 `box2 -> scatter2 -> rbdmaterialfracture2` 仍存在于同一网络中

右侧参数面板当前选中 `RBD Bullet Solver rbdbulletsolver1` 的碰撞页。图中能可靠辨认的设置包括：

在 `Collision Geometry` 区域：

- `Collision Type = Deforming`
- `Collision Shape = Convex Hull`
- `Collision Padding = 0.02`

在同页上方 `Physical` 区域：

- `Bounce = 0.5`
- `Friction = 1`

在 `Ground Collision` 区域：

- `Ground Type = Ground Plane`
- `Position = (0, 0, 0)`
- `Rotation = (0, 0, 0)`

在下方 `Physical` 区域还能确认：

- `Bounce = 0.5`
- `Friction = 1`
- `Dynamic Friction Scale = 1`

这张补充图的价值，在于把“碰撞体节点 `sphere1`”“破碎节点 `rbdmaterialfracture1`”“求解器 `rbdbulletsolver1`”三者的连接关系和实际模拟结果放在同一张图里。它证明教程这里采用的是很直接的测试链：先搭出 fracture，再加球体碰撞体，最后接入 Bullet 求解器观察碎片散开效果。

## 复现检查

- 先单独验证 Emitter 的 Spawn、Lifetime、Renderer 和材质，再叠加到完整 Niagara System。
- 节点名、模块名和参数值以关键截图中的实际 UI 为准；OCR 只用于辅助定位。
- 涉及透明、Additive、SubUV、Flipbook 或 Depth Fade 时，重点检查材质混合模式、Alpha/Opacity 与 Emissive 强度。
- 涉及蓝图、Sequencer 或 Montage 时，确认触发位置、触发时机、生命周期和销毁逻辑。
- 涉及 GPU/CPU Sim、Collision、Bounds 或 Local Space 时，单独验证可见性、性能和碰撞触发范围。

# 资产和内容包

> 路径：虚幻引擎5.7文档 / 理解基础知识 / 资产和内容包

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/assets-and-content-packs-in-unreal-engine

虚幻引擎项目中的所有内容片段都是 **资产** 。你可以将资产视为构建块，用于创建游戏和应用程序。

资产可以有许多不同的类型，例如静态网格体、材质、粒子系统和Sound Cue。一些资产在虚幻引擎外部创建（例如，在Maya或3ds Max等其他3D应用程序中）。而蓝图之类的其他资产直接在引擎中创建。

> [!NOTE]
> 你应该始终通过[内容浏览器](../content-browser/index.md)管理资产。

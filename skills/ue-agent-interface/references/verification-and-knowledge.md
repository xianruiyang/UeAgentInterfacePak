# 验证与知识

## 按实际缺口补证据

成功返回只证明该入口的公开合同。入口已经完成的 compile/settle、save/reload 和独立读回可直接消费，
不为了另取报告重复这些操作。HJSON 导入后的基线与完成语义见 [HJSON workspace](hjson-workspace.md)。

仅当目标要求且现有结果没有覆盖时补相应证据：缺目标字段就定向 Query，缺持久化证据才补保存/重载，
需要运行或视觉结果才执行对应观察；运行时 PIE 还须满足 [PIE 启动边界](../SKILL.md#先选择工作路径)。
现有读回不足且确需完整独立状态时才重新 export。
这不是固定检查清单；静态文件、authoring 输入或生成签名不能替代实际结果。

失败时停止依赖该结果的动作，先核对阶段、对象和实际合同；不要为通过改变目标。
证据只消费其对象、状态/版本和关系范围，不把单个消费者通过表述为全部能力完成。
场景设计约束、对象与阶段归属及公开操作由[从空间设计到UE搭建](scene-creation.md#从空间设计到ue搭建)组织；
场景专属的视口与空间查询按该页选择，本页维护通用证据边界，不另建场景检查清单。

需要原生错误/警告时用 `content_graph.diagnostics`：`kind=coverage` 说明实际读取的来源和状态，
`kind=diagnostic` 才是问题。查询不触发编译或运行；无问题条目不能消除 pending/stale/unavailable，
也不能证明尚未执行的内容已通过。按 coverage.sources 的 `owner/context/status` 判断来源：`observed` 只说明读到了该原生状态，PCG 保留的执行日志不证明当前图已执行；`not_applicable` 不代表已编译。
本次原生 compile/rebuild/refresh 完成由操作结果证明，当前快照诊断另属观察证据；不要要求定义资产具有使用者或预览实例的编译状态。已完成的操作结果可直接消费，无需另行编译或查源码确认。
Niagara emitter 的原生修复使用诊断中的 emitter 名、问题消息及 fix 描述，分别传入 `stack_issue_fix`
的 `emitter_handle_id/issue_id/fix_id`；只接受唯一匹配，不需要找隐藏身份。

## 运行与视觉任务

观察路径在入口选择；具体操作分别见[资产预览](asset-preview.md)、[场景制作](scene-creation.md)和[运行时 PIE](pie.md)。
视觉结论必须来自实际打开并查看的目标画面。capture完成、文件存在或结果中的`verified`等状态，
只证明对应工具合同，不证明模型看过或判断过画面；导入、编译成功也只说明相应处理完成。
无法辨认目标的黑图、遮挡、尺度不足、镜头在实体内或近墙裁切等画面，不能计为所问关系通过。
只为未看清的关系补合适视角或读回；异常黑面本身仍须区分几何、法线、遮挡与照明，不能直接用补光掩盖。
动态目标以覆盖相关过程的多帧/序列帧判断，单张静帧、播放状态或对象可见不能证明运动与连续性；
采样选择和实际时间判读见[预览截图与时间轴](preview-capture.md)。
画面无法区分目标资源与原生默认回退时，只补关键绑定的公开读回；对象可见不证明指定资源已正确生效。
验收对应最终交付版本；后续修改只补受影响证据：几何变化可能影响通行，单纯照明变化只补视觉。
旧画面和旧报告可证明历史状态，未变的关系可复用；不能凭旧状态为当前已变化的关系签发通过。
运行调试的修正与复验仍限于用户已明确的范围；已有结果满足目标时不为假想余量继续调参。
按本轮声明范围收尾，将必要读回、会话关闭、展示与有证据边界的摘要连续完成；
本轮不执行的验证明确保留，不以“少测”推导全通过。不影响交付的相邻问题另列，不扩成新的验收步骤。

## 知识来源

只有缺少会影响当前判断的知识时才补读：

- [ue-essential-knowledge](../../ue-essential-knowledge/SKILL.md) 提供 UE 关键基础知识、关卡设计原理与跨系统关系，不维护 UAI 操作流程。
- [ue-kb](../../ue-kb/SKILL.md) 提供版本敏感、source-backed 资料与来源检索：按所加载的知识包定位 manifest，检索运行时交给当前有效的 `kbcli-knowledge-base`，重要结论由 fetch 原文支撑。历史教程的固定轮次、制作顺序、阈值和检查清单是参考方法，不自动成为当前任务要求。
- 当前命令、字段和工作区操作由本 skill 及 Plugin/CMD 的正式合同说明；当前项目状态由公开 UAI 结果说明。

不因是 UE 任务就默认读取全部索引或教程。知识资料不能替代当前 UAI readback，UAI 结果也不替代版本事实查证。
具体任务的预热、计时与验收范围由该任务合同决定，本 skill 不另定测试时限或准备清单。

# Level Design Docs

## 目的

这里存放项目内长期复用的关卡白盒规则，不放单次交付说明或运行记录。

当前目录按“流程向导 -> 核心规则 -> 清单 -> 专题 -> 参考”组织，避免单一文档无限追加。

## 使用边界

- 这里优先保存长期复用的规则与方法。
- 具体关卡说明、交付说明、结构表默认仍放在 `docs/` 或 `docs/temp/`。
- 新增文档前，优先判断是否应并入现有主文档；只有形成新的长期独立主题时才新增。

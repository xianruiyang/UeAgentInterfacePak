### BC5

数据：RG88 - 两个通道。压缩率：128 位/块 = 1 字节/像素。块：[BC4] 2x Gray8 端点 + 16x 3 位索引 + [BC4] 与绿色通道相同。优点/缺点：[+] 适合切线空间法线，当提供 XY 时，Z 在着色器中重建（法线比 BC1 保留更多细节），[-] 只有 2 个通道 (RG)

### BC2

数据：RGB565+A4，RGB部分使用BC1，Alpha部分每像素4位。 * Alpha 不使用端点索引方案。压缩率：128 位/块 = 1 字节/像素。块：BC1 [ 2x RGB565 端点 + 16x 2 位索引 ] + 16x 4 位 Alpha（64 位 = 8 字节）。优点/缺点： [- ] 4 位 Alpha（16 个 Alpha 级别）引入了极端条带，[- ] 现在从未使用过，因为 BC3 在相同的压缩率下可以更好地压缩 Alpha * 自 Direct3D 11 起支持 BC6H、BC7。

### BC6H

数据：RGB bpc16F（RGB HDR 图像）。

压缩率：128 位/块 = 1 字节/像素。

块：模式位+（模式相关）分区索引+端点+索引。

优点/缺点：[+] RGB HDR 16F 数据：HDR 纹理、高度图、位移、精度至关重要的纹理，[+] 适用于没有符号变化的块（即

无符号变体），[-] 不支持 Alpha 理论基础。

SDR（标准动态范围）图像 - 每个通道存储 8 位整数（0 到 255）的通用图像。

HDR（高动态范围）图像每个通道存储 10+ 位整数或浮点（16F 或 32F）。

二进制 IEEE-754 标准中的 16F（16 位浮点，半精度）值可以是无符号或有符号的 [2]。

无符号：5 位指数 + 11 位尾数。

有符号：1位符号+5位指数+10位尾数。

// 指数：值的二进制大小，因此 Value= (-1)^Sign * (1.Fraction) * 2^Exponent。

// 尾数：值位的重要部分。

BC6H 将 4x4 像素块（每个像素为 RGB，即 3x F16（16 位浮点数））压缩为 128 位。

它将 float16 视为 16 个符号数值整数并对其进行线性插值 [2]。

特点和细微差别。

阿尔法。

BC6H 不支持 Alpha。

Alpha 始终被视为 1.0。

模式。

BC6H 块使用 14 种模式之一。

对于每个块，压缩器选择显示与未压缩的 4x4 块的最小偏差的模式。

不同模式的块如何存储模式位，请参阅“BC6H 模式布局”表。

模式定义块是否使用分区、颜色端点准确性以及端点是否使用增量压缩。

“BC6H 颜色端点”部分描述了增量压缩。

* 大多数软件仅使用 2 种模式 [1]。

分割。

在模式1到14中，10个模式1到10使用分区。

什么是分区？

与其他 BCn 压缩一样，BC6H 根据像素索引在两个颜色端点之间插入像素颜色。

然而，如果块有很多颜色变化，压缩器可能会判断一个插值区域（一对端点）不够。

不使用分区的块是一个插值区域（2个端点）。

使用分区的块被分成两个插值区域，每个插值区域有 2 个端点。

BC6H 块使用 5 位来指定 2^5= 32 个分区之一。

所有 32 种分区模式都硬编码到硬件中，或者作为由 Khronos 和 Microsoft 的 BC6H 标准定义的 16 位二进制序列进行压缩和解压缩。

端点。

像素通道数据（未压缩）为 float16。

输入 float16 可以等于 INF、-INF 或 NaN（非数字）。

压缩机将 INF 转换为最大值，将 -INF 转换为最小可能值，将 NaN 转换为 0 值。

BC6H 颜色端点是 RGB 通道的 3x F16 值。

在压缩块中，每个通道值可以是不同的位数，具体取决于块模式和通道。

有关详细信息，请参阅“模式布局”表。

显式和压缩的端点。

增量压缩 [2, 3]。

与显式存储每个端点不同，显式存储第一个 (c0) 端点和其他端点（c1，对于两区域块，c2 和 c3）作为距 c0 的距离（增量）是有益的。

因此，c0 是显式的，c1delta= c1-c0，c2delta= c2-c0，c3delta= c3-c0。

使用增量压缩时，c0 通常大于 c1d、c2d、c3d。

这允许为显式 c0 分配更多位，为 c1d、c2d、c3d 偏移分配更少位，从而提高解压缩 c1、c2 和 c3 的整体精度。

显式端点显式表示其位域值范围内的 RGB 值。

Delta 压缩端点 cX 存储 cX 和 c0 之间的距离：(cX - c0)，其中 cX 是该端点 X 的显式值，c0 是计算 delta 的第一个（参考）端点的显式值。

端点的符号扩展（可能与本手册的目的无关）。

端点可以进行符号扩展。

仅当 format 已签名时，c0 才会签名。

仅当端点格式转换已签名时，其他端点才会签名。

这适用于 1 区域和 2 区域模式。

### BC7

数据：RGB(A) - 支持 Alpha，精度取决于模式。

压缩率：128 位/块 = 1 字节/像素。

块：模式 ID +（模式相关）分区 +（模式相关）旋转 +（模式相关）索引选择器 + 端点 + 索引。

BC7 将 4x4 像素的图块（每个像素为 RGB(A)）压缩为 128 位 [7]。

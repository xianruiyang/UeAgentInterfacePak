# 虚幻引擎5！使用 PCG 生成屋顶 - 第 3 部分

## 知识目标

- 围绕“虚幻引擎5！使用 PCG 生成屋顶 - 第 3 部分”整理真实 PCG 建筑生成第 3 部分：在多楼层建筑基础上生成屋顶、屋顶窗、材质、Decal 和最终细节，使 PCG 建筑从框架进化为完整可用的建筑资产。

## 可复现主流程

- 先修正上一集遗留问题，确认楼层点、顶层点和墙体点都能正确分离。
- 从最后一层生成 Roof Points，并用 Transform Points 把屋顶点移动到正确高度。
- 复用 Split/Subgraph 逻辑，把屋顶点拆成 Corner、Wall、Pillar 等类别。
- 先生成屋顶角件和屋顶边缘，再逐步添加 Roof Static Mesh Spawner。
- 制作或导入 Roof Piece，并为屋顶模块设置正确尺寸和 Pivot。
- 给屋顶材质设置 World Aligned Texture，让不同尺寸屋顶仍有稳定纹理比例。
- 根据屋顶边长计算重复次数和偏移，避免屋顶模块在边缘处错位。
- 处理墙顶和屋顶之间的过渡模块，让屋顶不会悬空或插入墙体。
- 加入 Roof Window Repetition，控制屋顶窗是否生成以及生成间隔。
- 用 Attribute/Filter 按密度、索引或重复参数筛选屋顶窗点。
- 把普通屋顶件和带窗屋顶件分开生成，避免两个 Mesh 在同一位置重叠。
- 处理门、窗、Decal 等立面细节，让建筑外观不再是重复模块。
- 用 Density Filter 和 Attribute Noise 随机化 Decal 或污渍/细节分布。
- 调整 Decal 材质、Opacity、位置偏移和朝向，使贴花落在正确表面。
- 合并屋顶、墙体、窗、门、Decal 各分支，检查所有模块之间的遮挡和重叠。
- 整理参数，把屋顶重复、窗重复、材质和 Decal 控制暴露为可调项。
- 在不同建筑尺寸上测试屋顶和窗的适配性，确保宽、长、高变化后仍然可用。
- 完成整套建筑生成器收尾，确认从单层、多楼层到屋顶细节都能在 PCG 中稳定生成。
- 记录后续可扩展方向：替换资产包、增加更多屋顶类型和更复杂立面规则。

## 复现检查清单

- Roof Points 必须来自最后一层点，而不是所有楼层点，否则屋顶会重复生成在每层。
- 屋顶 Mesh 的 Pivot 和尺寸要准确，重复偏移才不会错位。
- World Aligned Texture 可降低缩放导致的纹理拉伸，但材质节点要正确接入 World Position。
- 屋顶窗和普通屋顶件需要互斥过滤，否则同一位置会重叠。
- Decal 的密度、透明度和偏移要单独调试，避免贴花穿到门窗或屋顶背面。
- 最终要用不同建筑宽长高测试，因为屋顶逻辑最容易在边界尺寸下出错。
- 复现时先固定随机种子，再调整密度、过滤和生成资源，避免随机结果掩盖逻辑错误。

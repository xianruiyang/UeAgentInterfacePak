## Gameplay调试器

| **分段** | **说明** |
| --- | --- |
| **输入（Input）** | 激活码，类别和类别行的快捷方式。 |
| **显示（Display）** | 调试画布填充和文本阴影的设置。 |
| **加载项（Add-Ons）** | 设置游戏加载项（AI、行为树、EQ、寻路网格体、感知、寻路网格、GameHUD和旁观者）。 |

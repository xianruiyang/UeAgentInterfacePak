# DMX工具

> 路径：虚幻引擎5.7文档 / 使用媒体 / 与媒体组件通信 / DMX / DMX工具

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/dmx-tools-in-unreal-engine

虚幻引擎提供了多种强大的工具，帮助你控制包括现场和数字装置在内的DMX装置。关于如何使用这些工具，以及如何将它们整合进你的DMX项目，请参阅下列文档。

- [DMX Activity and Channel Monitors](dmx-activity-and-channel-monitors/index.md) - Use the DMX Activity and Channel Monitors to track your DMX installations.

- [DMX冲突监控器](dmx-data-conflict-monitoring/index.md) - 关于DMX冲突监控器的信息，它可检查虚幻引擎中的DMX工具之间的潜在数据冲突。

- [DMX Control Console](dmx-control-console/index.md) - Use the Control Console to control your fixtures using your library and patch selection.

- [DMX Patch Tool](dmx-patch-tool/index.md) - Use the DMX Patch Tool to quickly apply DMX Libraries and Patches.

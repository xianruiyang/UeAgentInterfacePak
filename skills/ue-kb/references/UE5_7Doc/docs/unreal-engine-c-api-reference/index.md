> 路径：虚幻引擎5.7文档 / Unreal Engine C++ API Reference

该页面没有可用的官方中文版本；以下内容保留原文，并按本项目人工译文规则逐步回译。

欢迎阅读 Unreal Engine C++ API 参考。这是从 Unreal Engine 源代码自动生成的参考手册。 如需了解使用 Unreal 编程的教程、流程演练和详细指南，请查看在线文档： [Programming in Unreal Engine](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-engine-programming-and-scripting).

Unreal Engine 的系统和功能以两种方式组织：

- 模块

  : Unreal Engine 软件与架构的基础构建单元。
- 插件

  : 模块与资产的集合，可在编辑器中按项目启用或禁用。

这里按层级组织了 Unreal Engine 的所有模块、插件及其成员。你可以使用搜索栏查找已知术语，例如类名或函数名。

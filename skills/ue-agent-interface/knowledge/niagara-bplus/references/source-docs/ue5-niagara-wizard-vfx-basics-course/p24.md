- 这一页的操作重点
  柱子烟雾统一发射的关键不在单独手摆多个发射器，而是在 `Static Mesh Location` 中把 `Pillars_...` 这组静态网格当作采样源
  通过 `Triangles + Random (All Triangles)`，粒子会在整组柱体三角面上随机出生
  再配合 `Write To Particle Position` 和后面的 `Set Fluid Source Attributes`，这些粒子就会被送进 3D Gas 系统，形成多个柱子同时出雾的效果
  在此之前，必须先用 `Fix Now` 解决 CPU access error，否则这些表面采样数据并不可靠

- 节点名、模块名和参数值以关键截图中的实际 UI 为准；OCR 只用于辅助定位。

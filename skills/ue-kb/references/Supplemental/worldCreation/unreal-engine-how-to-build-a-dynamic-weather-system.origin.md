### 了解虚幻引擎 5.4

### 虚幻引擎5.4简介

Unreal Engine 5.4 由 Epic Games 开发，是流行游戏引擎的最新版本，以其高保真图形和强大的工具集而闻名。该版本带来了新功能和改进，可以更轻松地创建复杂的、视觉上令人惊叹的游戏。

### 主要特点

1. Nanite：虚拟化几何体，可实现前所未有的细节水平。 2. Lumen：用于真实照明的全动态全局照明解决方案。 3. MetaSounds：用于创建动态音景的高性能音频系统。 4. 增强的动画和绑定工具：实现更真实的角色动作。

### 系统要求

在深入了解虚幻引擎 5.4 之前，请确保您的系统满足以下要求： 1. 操作系统：Windows 10 64 位 2. 处理器：四核 Intel 或 AMD，2.5 GHz 或更快 3. 内存：16 GB RAM 4. 显卡：NVIDIA GeForce GTX 970 / AMD Radeon RX 470 或更高版本 5. 存储：50 GB 可用空间

### 设置您的项目

### 创建一个新项目

1. 打开 Epic Games 启动器。 2. 导航至虚幻引擎选项卡。 3. 单击“新建项目”并选择“空白”或“第三人称”模板。 4. 为您的项目命名并选择要保存它的目录。 5. 单击“创建”以设置您的项目环境。

### 项目设置和配置

1. 转到“编辑”>“项目设置”。 2. 配置常规设置，例如地图和模式、输入、渲染等，以满足您的项目需求。 3. 确保您的项目设置为使用 DirectX 12，以便通过虚幻引擎 5.4 的高级功能获得更好的性能。

### 动态天气简介

### 什么是动态天气系统？

动态天气系统模拟随时间变化的真实天气条件，增强游戏的沉浸式体验。它包括天气状态之间的转换，例如晴空、雨和雪。

### 动态天气系统的好处

1. 增强沉浸感：增加游戏环境的真实感和深度。 2. 游戏机制：可以影响玩家的行为和策略。 3. 审美吸引力：使游戏具有视觉吸引力和活力。

### 蓝图与 C++

### 使用蓝图的优点

1. 易于使用：可视化脚本编写，不需要深厚的编程知识。 2. 快速原型制作：快速测试和迭代游戏功能。 3. 社区支持：提供丰富的文档和教程。

### 何时使用 C++

1. 性能：适用于需要高效率和速度的任务。 2. 复杂系统：构建更高级和定制的游戏机制时。 3. 集成：集成Blueprints不支持的第三方库或系统。

### 创建天气控制器

### 设计天气控制器

天气控制器是动态天气系统的核心。它管理天气影响的状态和转变。 1. 创建一个派生自 Actor 的新蓝图类。 2. 将其命名为WeatherController。 3. 添加不同天气状态的变量（例如晴、雨、雪）。

### 实施基本天气状态

1. 在 WeatherController 内，创建一个 WeatherState 枚举，其中包含每种天气类型的值。 2.增加改变天气状态并触发相应效果的功能。

### 添加天气效果

### 创建云系统

1. 使用体积云 actor 创建逼真的云结构。 2. 调整密度、覆盖范围、光照等参数以达到预期效果。 3. 制作云移动和过渡的动画。

### 实施降雨效果

1. 创建降雨粒子系统。 2. 使用Niagara或Cascade设计雨粒子。 3. 将粒子系统附加到WeatherController 并在下雨时激活它。

### 添加雪效果

1. 与雨类似，为雪创建一个粒子系统。 2. 微调粒子属性来模拟雪花。 3. 确保与游戏环境的正确碰撞处理。

### 照明和环境影响

### 动态照明技术

1.使用Lumen进行实时全局照明。 2. 根据天气条件调整照明强度和颜色（例如，暴风雨时照明较暗）。

### 现实的环境影响

1. 实现雾和薄雾效果来增强气氛。 2.使用后处理体积动态调整视觉效果。

### 管理资源

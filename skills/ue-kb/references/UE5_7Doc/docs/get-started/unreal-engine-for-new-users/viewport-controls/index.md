# 视口控制方式

> 路径：虚幻引擎5.7文档 / 入门指南 / 虚幻引擎新用户指南 / 视口控制方式

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/viewport-controls-in-unreal-engine

虚幻引擎使用**视口**来直观地呈现项目中的对象。 这包括使用关卡编辑器视口时世界中的对象，或使用单个工具编辑器（比如材质编辑器、动画模式编辑器和Niagara系统编辑器）的视口时世界中的对象。 所有这些视口的导航方式都相似，便于你查看对象在游戏或关卡编辑器视口中所呈现的光照和材质效果。

在创建游戏时，你通常会将大部分时间花在关卡编辑器上，因此关卡编辑器的视口是学习导航操作的绝佳示例。

本页面列出的大量视口设置和面板都假定你已经阅读了入门系列的上一篇文章，即[虚幻编辑器界面](../unreal-editor-interface/index.md)，该文介绍了虚幻引擎最常见的元素。 如果你尚未阅读该文章，建议你先完成阅读，以初步了解虚幻编辑器的界面。

## 本页所用缩写

我们将在本文中通篇使用以下缩写：

| 控制方式 | 缩写 |
| --- | --- |
| 鼠标左键 | LMB |
| 鼠标中键 | MMB |
| 鼠标右键 | RMB |

我们将控制方案按其各自的列表做了区分，其一负责**透视（Perspective）**视图，另一份负责**正交（Orthographic）**视图。 透视视图适合用于在三维（3D）空间中编辑关卡，而正交视图适合用于在二维（2D）空间中进行编辑，例如顶视图、底视图或侧视图视角。

下文部分控制方式可在**键盘快捷方式（Keyboard Shortcuts）**中配置，该选项的路径为**编辑（Edit） -> 编辑器偏好设置（Editor Preferences） -> 通用（General） -> 快捷按键（Keyboard Shortcuts）**。 本页列出了所有快捷方式的默认状态。 如果你对它们进行了更改，它们可能不匹配。

## 选择关卡中的对象

选择关卡编辑器视口中的对象后，你可以使用**细节（Details）**面板编辑对象的属性，并在视口中移动、旋转和缩放。

| 控制方式 | 操作 |
| --- | --- |
| 透视视图： |  |
| 按下LMB | 选择光标下的对象。如果已经有选中的对象，则替换当前所选项。 |
| 按住Ctrl / 按住Shift + 按下LMB | 将光标下的对象添加到当前所选项中。 |
| 正交视图： |  |
| 按下LMB | 选择光标下的对象。如果已经有选中的对象，则替换当前所选项。 |
| 按住LMB + 拖动鼠标 | 创建选框以选中多个对象。如果已经有选中的对象，则替换当前所选项。 |
| 按住Shift + 按住LMB + 拖动鼠标 | 将选框内的对象添加到当前所选项中。 |
| 按住Ctrl + 按住RMB + 拖动鼠标 | 从当前所选项中移除选框内的对象。 |

## 关卡导航

你可以通过多种方式在视口中导航。 有些操作可以完全用鼠标完成，有些可以用键盘完成，更多时候则是两者结合使用。

#### 在视口中环顾

使用下方控制方式，你可以仅用鼠标在视口中进行环顾。 下文还专为妙控鼠标和妙控板给出了额外控制方式组合说明。

| 透视 | 正交 |
| --- | --- |
|  |  |

##### 使用常规鼠标

| 控制方式 | 操作 |
| --- | --- |
| 透视 |  |
| 按住LMB + 拖动鼠标 | 前后移动摄像机，并左右旋转。 |
| 按住RMB + 拖动鼠标 | 旋转摄像机以环顾关卡。 |
| 按住LMB + 按住RMB + 拖动鼠标 按住MMB + 拖动鼠标 | 使摄像机上移、下移、左移或右移，且不旋转摄像机。 |
| 向上或向下滚动MMB | 使摄像机逐渐前移或后移。 |
| 正交 |  |
| 按住LMB + 拖动鼠标 | 创建选框以选中多个对象。 |
| 按住RMB + 拖动鼠标 | 使摄像机平移。 |
| 按住LMB + 按住RMB + 拖动鼠标 | 使摄像机前移或后移。 |
| 向上或向下滚动MMB | 使摄像机逐渐前移或后移。 |

##### 使用妙控鼠标和妙控板

| 妙控鼠标控制方式 | 妙控板控制方式 | 操作 |
| --- | --- | --- |
| 透视 |  |  |

| 按住RMB + 拖动鼠标 | 双指点击 + 拖动 | 旋转视口摄像机。 |
| 按住LMB + 按住RMB + 拖动鼠标 按住MMB + 拖动鼠标 | 双指点触 + 拖动 | 旋转视口摄像机。 |
| 在多点触控表面上向上或向下滚动 | 在多点触控表面上向上或向下滚动 | 使摄像机逐渐前移或后移。 |

#### 在关卡中移动

在透视视图视口中，你可以使用下列控制方式移动摄像机的位置。

| 控制方式 | 操作 |
| --- | --- |
| 按住RMB + 向上或向下滚动鼠标滚轮 | 增加/降低摄像机的移动速度。 |
| 按住RMB + W / 数字键盘8 / 上箭头 | 使摄像机前移。 |
| 按住RMB + S / 数字键盘2 / 下箭头 | 使摄像机后移。 |
| 按住RMB + A / 数字键盘4 / 左箭头 | 使摄像机左移。 |
| 按住RMB + D / 数字键盘6 / 右箭头 | 使摄像机右移。 |
| 按住RMB + E / 数字键盘9 / 向上翻页 | 使摄像机上移。 |
| 按住RMB + Q / 数字键盘7 / 向下翻页 | 使摄像机下移。 |
| 按住RMB + Z / 数字键盘1 | 抬升摄像机的视野。 |
| 按住RMB + C / 数字键盘3 | 降低摄像机的视野。 |

#### 让摄像机环绕对象或枢轴点

你可以在虚幻引擎中使用下列控制方式在视口中进行平移、环绕和缩放操作。 使用Maya和Unity等特定3D工具的用户可能早已熟悉这些操作。

| 控制方式 | 操作 |
| --- | --- |
| 按下F | 将摄像机聚焦到关卡中的选定对象。 |
| Alt +按住LMB + 拖动鼠标 | 让摄像机环绕单个枢轴点或兴趣点。 兴趣点可以是你用F键所聚焦的对象。 |
| Alt +按住RMB + 拖动鼠标 | 用移动车将摄像机朝向或远离一个枢轴或目标点移动（缩放）。 |
| Alt +按住MMB + 拖动鼠标 | 沿着鼠标移动的方向向左、向右、向上、向下追踪摄像机。 |

#### 移动、旋转和缩放关卡中的对象

在视口中，你可以使用变换（Transform）工具来**移动**、**旋转**和**缩放**选中的对象。

| 平移工具 | 旋转工具 | 缩放工具 |
| --- | --- | --- |
|  |  |  |

你可以使用视口左上方的选项查看当前激活的工具，并切换为其他工具。 你也可以使用对应的快捷方式来切换不同的变换工具。

所有工具提供的三向轴都可以被鼠标拖曳，即**X轴**、**Y轴**和**Z轴**。 点击并拖曳任意轴都能执行对应方向上的操作。

你可以使用下列控制方式来 移动、 旋转和 缩放 关中的对象：

| 控制方式 | 操作 |
| --- | --- |
| 空格键 | 在移动、旋转和缩放工具之间切换。 |
| Q | 选择"选择"工具。 |
| W | 选择"平移"工具。 |
| E | 选择"旋转"工具。 |
| R | 选择缩放工具。 |
| 在视口中按住某项工具的轴小工具，并按住LMB + 拖动鼠标 | 移动、旋转或缩放某个对象的具体效果取决于当前所选的变换工具。 |
| 按住V | 切换顶点对齐，以对齐到世界中其他几何体的顶点。 顶点对齐仅对平移工具适用。 |
| 按住MMB + 在对象的枢轴点上拖动鼠标 | 暂时平移所选对象的枢轴点，以偏移变换效果。 |

凭借变换工具，你还可以沿多条轴执行移动和缩放操作。 你可以通过高亮显示的方式来识别当前被移动或缩放的轴。 例如，在使用平移和缩放工具时，可以使用视口中小工具中心的枢轴点来统一移动或缩放。 或者，你可以将鼠标悬停在两个轴上，进而只在这两个方向上移动或缩放。

> [!NOTE]
> 使用正交视图时，你将只能沿两个轴移动或缩放，而不能在所有方向上移动或缩放。

#### 显示控制方式

你可以使用下列控制方式更改关卡在视口中的显示方式。

| 控制方式 | 操作 |
| --- | --- |
| G | 切换**游戏模式（Game Mode）**，使视口只渲染游戏中可以看到的内容。这将使仅编辑器中可见的小工具和体积轮廓都不可见。 |
| 按住CTRL + 按下R | 在活动视口中开关实时播放。 关闭实时播放后，某些特效（如天空中的体积云）将不会再动态地移动或更新。关闭实时视口对于性能占用程度较高的场景非常有用。 |
| F11 | 开关沉浸模式，使视口全屏显示。 |

#### 使用编辑器偏好设置更改视口选项

你可以通过**编辑器偏好设置（Editor Preferences）**自定义视口的导航、控制和整体外观。 要访问这些选项，请转至**编辑（Edit） > 编辑器偏好设置（Editor Preferences） > 关卡编辑器（Level Editor） > 视口（Viewports）**。

你可以在**控制（Controls）**分段中调整与视口导航相关的设置，如摄像机移动速度和鼠标灵敏度等。 你可以在**外观（Look and Feel）**分段中定制视口的外观和行为，以使其符合自己的偏好。 这包括启用轨迹球旋转、启用平移/旋转控件组合，以及调整所选项高亮显示的亮度等选项。

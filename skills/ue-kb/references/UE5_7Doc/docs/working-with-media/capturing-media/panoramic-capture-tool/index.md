> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/panoramic-capture-tool-in-unreal-engine

> [!WARNING]
> Epic Games不再支持或维护全景采集插件。它只在你希望自行创建解决方案时作为参考存在。该插件可能无法正常工作。

## 介绍

翻页动画纹理是一种强大的技术，可用于在实时应用程序中创建动画效果，它允许您使用存储在单个纹理图集中的图像序列来显示复杂的动画。传统上，创建翻页动画需要 Blender、Maya 或 Substance Designer 等外部 DCC（数字内容创作）工具，这会增加工作流程的步骤，并且需要您在不同的软件包之间切换。 Unreal Engine's Niagara system changes this entirely by providing a built-in baker tool that allows you to create flipbook textures directly within the engine—no

虚幻引擎的 Niagara 系统彻底改变了这一现状，它提供了一个内置的烘焙工具，可以直接在引擎内创建翻页动画纹理，无需任何外部软件。这种简化的工作流程意味着，您可以将项目中的任何静态网格体渲染成动画翻页动画纹理，并立即将其用于材质中。

## 本教程分为两个主要部分：

第一部分：在 Niagara 中创建翻页动画 - 您将学习如何设置 Niagara 系统来渲染旋转的静态网格，并将其烘焙成 8x8 的翻页动画纹理图集。我们将介绍正确的相机取景、分辨率设置，以及如何避免常见的陷阱，例如丢帧。

第二部分：创建动画材质 ——您将构建一个可自定义的叠加材质，通过实时动画控制，让您的翻页书栩栩如生。该材质将包含动画速度、颜色色调和发光强度等参数，非常适合创建科幻全息效果、用户界面面板和其他风格化的视觉元素。

在本教程结束时，您将拥有一个完整的、可重复使用的工作流程，用于完全在虚幻引擎中创建动画翻页书效果。

第一部分：在 Niagara 中创建翻页书

设置您的项目

首先整理你的内容。在内容浏览器中创建一个名为“翻页书”的新文件夹，将所有相关素材集中存放。本教程需要一个静态网格体来进行动画制作。你可以在 Fab 上找到免费素材，按价格筛选，并选择“仅显示免费产品”。

创建尼亚加拉系统

在内容浏览器中右键单击，选择“Niagara 系统”。从模板选项中，导航到“模板”文件夹，然后选择“极简”模板——这将提供一个干净的起点，不包含不必要的模块。将系统命名为“NS_Flipbook”，然后双击打开它。

默认的最小模板自带精灵渲染器，但由于我们使用的是静态网格，因此需要进行一些更改。选中精灵渲染器模块并将其删除。然后，添加网格渲染器模块。展开网格渲染器中的“网格”部分，并选择您所需的静态网格（在本例中为手榴弹）。

首先，设置纹理分辨率。为了获得良好的质量，建议从 2048 x 2048 (2K) 开始。但是，请注意纹理内存的使用情况——根据效果在项目中的显示范围来选择分辨率。 Critical setting:

关键设置：将时间范围设置为 1 到 4，而不是默认的 0 到 4。这样可以防止翻页动画跳过第一帧，从而避免动画中出现明显的闪烁。

## 烘焙翻页书

配置完成后，点击“烘焙”按钮。该过程需要几秒钟，具体时间取决于您的分辨率设置。Niagara 会渲染动画的每一帧，并将它们打包成一个 8x8 的网格纹理。

面板右侧的“烘焙场景预览窗口”会实时显示您的动画，让您在确认素材之前验证结果。

完成后，纹理会自动保存到与 Niagara 系统相同的文件夹中。双击纹理即可打开。您可以禁用 Alpha 通道以清晰地查看完整的翻页动画网格——您应该可以看到 64 帧（8x8），显示您的网格平滑旋转，没有任何跳帧现象。

## 制作翻页动画

在材质图中右键单击并搜索“Flipbook”。虚幻引擎提供了一个便捷的 Flipbook 材质函数，它会自动处理所有 UV 偏移和动画逻辑。

函数需要知道纹理图集的尺寸。创建一个 Constant 1 节点，并将其值设置为 8，因为我们烘焙了一个 8x8 的网格。将此 Constant 节点连接到 Flipbook 函数的 Rows 和 Columns 输入端。 Now you need to drive the animation. Right-click and search for the Time node—this

现在你需要驱动动画。右键单击并搜索“时间”节点——这将显示当前经过的时间（以秒为单位）。

创建一个“乘法”节点。将“时间”节点连接到“乘法”节点的输入 A。右键单击“乘法”节点的输入 B，然后选择“提升为参数”。将此参数命名为“速度”。这样，您就可以在不编辑主材质的情况下调整材质实例中的动画速度。默认值设置为 1。

将乘法节点的输出连接到翻页动画函数的动画阶段输入。 Adding Colour 添加色彩

功能输出 RGB 颜色信息，虽然您可以将其直接连接到 Emissive，但添加颜色色调可以创造出更具风格化的全息效果。

创建一个“常量 3”节点。右键单击该节点，选择“转换为参数”。将其命名为“颜色”。在参数的默认值中，选择一个符合您全息美学风格的颜色。

创建另一个“乘法”节点。你需要将翻页纹理的一个通道与颜色参数相乘。将翻页函数的红色通道（R 输出）连接到“乘法”节点的一个输入端，将颜色参数连接到另一个输入端。 Why just the red channel?

为什么只用红色通道？这样可以产生一种有趣的亮度效果，翻页书中较亮的区域会呈现出你选择的颜色饱和度更高。你也可以尝试绿色 (G) 或蓝色 (B) 通道——每个通道都会产生略微不同的效果。 Adding Intensity Control 增加强度控制

为了控制全息图的亮度，您可以添加强度倍增器。

再创建一个乘法节点。将上一个乘法运算的输出（着色后的结果）连接到输入 A。右键单击输入 B，将其转换为参数。将其命名为“强度”，并将默认值设置为 1。

将最终乘法运算的输出连接到主材质节点的发光颜色输入。

点击“应用”按钮编译资料，然后点击“保存”。您的资料现在可以使用了。

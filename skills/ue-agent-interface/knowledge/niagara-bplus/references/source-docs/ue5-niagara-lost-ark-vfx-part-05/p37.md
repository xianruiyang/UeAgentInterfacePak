- `Velocity_Str = 0`

- `Run Over = Points`
- `Vex Source = Myself`
- `Export Parameters = *`
- `Enable Multithreading` 已启用

左侧视口里只剩一簇较亮的小点，没有明显拉长的速度线显示，说明当 `Velocity_Str` 被降为 `0` 时，`pointvop1` 不再给这些辅助点写入有效的初始速度量。结合上一帧 `Velocity_Str = 5` 的对比，可以明确确认：后续 RBD 初速度差异确实来自这个参数控制，而不是其他节点或默认求解设置。

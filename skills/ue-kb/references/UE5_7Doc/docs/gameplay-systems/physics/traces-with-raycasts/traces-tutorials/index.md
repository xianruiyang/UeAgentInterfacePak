# 追踪指南

> 路径：虚幻引擎5.7文档 / Gameplay系统 / 物理 / 使用射线进行命中判定 / 追踪指南

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/traces-tutorials-in-unreal-engine

以下指南为你展示了如何在虚幻引擎中使用追踪（光线投射）。

## 教程

- [使用 Multi Line Trace (Raycast) by Channel](using-a-multi-line-trace-raycast-by-channel/index.md) - 此指南说明如何使用 Multi Line Trace by Channel 蓝图节点返回在 Visilibity 通道上响应的所有 Actor，并输出它们的名称。

- [使用 Multi Line Trace (Raycast) by Object](using-a-multi-line-trace-raycast-by-object/index.md) - 此指南说明如何使用 Multi Line Trace by Object 蓝图节点返回其命中的全部世界动态 Actor，并输出它们的名称。

- [使用 Single Line Trace (Raycast) by Channel](using-a-single-line-trace-raycast-by-channel/index.md) - 此指南说明如何使用 Single Line Trace by Channel 蓝图节点返回命中的首个 Actor（在 Visibility 通道上形成响应），并输出其名称。

- [使用 Single Line Trace (Raycast) by Object](using-a-single-line-trace-raycast-by-object/index.md) - 此指南说明如何使用 Single Line Trace by Object 蓝图节点返回其命中的首个世界动态 Actor，并输出其名称。

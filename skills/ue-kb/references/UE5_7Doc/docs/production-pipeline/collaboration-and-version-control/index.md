# 虚幻引擎中的协作和版本控制

> 路径：虚幻引擎5.7文档 / 建立你的开发流程 / 虚幻引擎中的协作和版本控制

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/collaboration-and-version-control-in-unreal-engine

虚幻引擎中整合了两种版本控制软件的完整功能，让大家在项目上能够协同工作，这两个软件是 Perforce 和 SVN。

版本控制软件能在团队的成员之间共享资源文件或代码文件，并能够提供存储备份以及文件的历史记录，能在某些文件发生问题时回滚到早先的可用版本上。

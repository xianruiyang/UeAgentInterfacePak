### 00:00:05-00:04:40 Niagara、Emitter、材质

- 本段定位：Niagara、Emitter、材质。
- 知识点：在我们实际使用Niagara生成任何例子之前 让我们先讲一下它的结构 以这个VFX为例 在Niagara术语中,这被称为Niagara系统。
- 知识点：Niagara系统只是一个发射器容器 可以放置或在世界中生成 注意系统本身 它不发射任何例子 实际生成例子的东西是 Niagara发射器并且。
- 知识点：一个系统可以有任意数量的发射器 通常为了创建一个VFX 我们需要不同Niagara发射器一起工作。
- 知识点：Niagara发射器的工作很简单 它只是发射和控制例子 所以让我们创建第一个Niagara发射器。
- 知识点：可观察到有很多东西 与Niagara相关的内容,可以选择 我们现在不需要担心这些 现在我只需要创建 一个Niagara发射器,一旦我点击它。
- 知识点：可观察到一个窗口弹出 有三个选项可以选择 我不会使用第一个和第二个 而是使用第三个 第三个选项允许我们创建 一个没有模块或渲染器的空发射器。
- 知识点：这是完美的 后续会从头开始 然后我点击这个完成 现在可观察到 一个Niagara发射器已经为我创建好了。
- 复现要点：Spawn Rate、Burst 或 Spawn Per Unit 决定生成节奏，需要和 Lifetime 配合控制屏幕密度。
- 复现要点：Renderer 决定最终可见形态；Sprite、Mesh、Ribbon 的材质、朝向、排序和尺寸语义不同。
- 复现要点：材质侧要核对 Blend Mode、Opacity/Alpha、Emissive、UV/Panner、Depth Fade 或 SubUV/Flipbook 的真实连接。

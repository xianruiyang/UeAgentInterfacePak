## 中文整理

### 📌简介

在本教程中，我们将构建一个自动塔的基础系统，当玩家进入其范围时，该系统会检测到玩家，保存对其的引用并开始瞄准他。我们将使用**虚幻引擎 5.5 中的蓝图**来完成这一切，而无需使用 C++。我们将使用一个简单的场景，其中有一座塔，该塔具有旋转部分 (Cube1) 和用作感知区域的碰撞球体 (Detect)。

### 🧠 一般逻辑

1. 我们使用 Detect 组件的 OnComponentBeginOverlap 来检测玩家。 2. 如果玩家进入范围，我们将引用保存在 Pawn 变量中。 3. 在每个 Tick 上，我们检查是否存在有效目标。 4. 如果有，我们计算朝向它的方向并旋转塔顶（Cube1）以指向它。 5. 当离开该区域时，我们删除参考，以便塔停止指向。

### 🔧 瞄准功能

目标功能是旋转系统的核心。它的作用如下： 1. 获取 Cube1 组件（塔的旋转部分）的位置。 2. 获取Pawn（目标，通常是玩家）的位置。 3. 计算两者之间的方向向量（减去目标位置减去塔的位置）。 4. 标准化该向量以避免幅度误差。 5. 使用 VectorToRotator 函数将结果向量转换为旋转 (Rotator)。 6. 使用 SetWorldRotation 将旋转应用到 Cube1。 🎁 **可选额外（强烈推荐）：** 如果您希望塔仅在水平（偏航）轴上旋转，您可以使用“Break Rotator”节点并仅使用该值构建一个新节点。如果玩家处于较高或较低的位置，这可以防止塔倾斜。

### 🧪 完整的行为

1. 当你开始时，塔没有指向任何东西。 2. 当玩家进入范围（Detect → OnBeginOverlap）时，他的参考将被保存。 3. 在Tick中，塔调用Aim，计算方向并旋转。 4. 如果玩家离开该区域 (EndOverlap)，参考将被清除并且他将停止瞄准。

这种模块化系统可让您轻松构建用于射击游戏、防御游戏或治安敌人的智能塔。您可以将其扩展以进行射击、搜索新目标或在旋转时显示动画。

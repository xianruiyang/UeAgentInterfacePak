# 1-7 - Create the Black Spruce Tree

## 知识目标

- 本文整理“1-7 - Create the Black Spruce Tree”的 PCG 实操流程、关键节点、参数组织方式和复现风险点。

## 可复现主流程

- 把树干和多组枝条变体组装成完整黑云杉，先建立主枝层级，再用小枝填补空洞。
- 控制枝条旋转、缩放、层级间距和朝向，让树冠从多个角度看都不露空。
- 制作多个树形或枝条组合变体，为后续 PCG/foliage 分布提供随机性。
- 检查资产复杂度、材质槽数量、碰撞和导出设置，保证 UE5 中能作为环境资产使用。

## 复现检查清单

- 组装阶段要同时看近景枝条细节和远景剪影，单一视角好看不等于可用于开放环境。
- 所有 UE5 资产都要检查比例、pivot、材质槽、贴图色彩空间和实例化性能。
- 复现时先固定随机种子，再调整密度、过滤和生成资源，避免随机结果掩盖逻辑错误。

### 00:04:04-00:07:07 蓝图、颜色

- 本段定位：蓝图、颜色。
- 知识点：小数点可以非常长的一吊式 可以是非常小的数也可以是非常大的数 是一个固定的数字 是的 这被称为浮点或标量 可以用这个概念 但这样说会有点难。
- 知识点：简单来说就是在讨论时常说只有一个通道的形式 因此这个浮点通道 四个聚在一起就形成这个颜色。
- 知识点：为了简单展示这个由四个通道组成 这样单独连接时就变成两个通道 那么在这里两个通道再加上一个通道就变成三个通道 而三个通道有时被称为向量。
- 知识点：因为这三个通道最终由三个通道组成 3C, 4A, 4H, 4B这也是一个共同的概念 并且由这三个通道组成的可以是一个位置 或者指向某个方向。
- 知识点：所有这些都称为向量 是的 所以有时会有各种表达方式进行解释 但总是这个数据的类型由三个通道组成的浮点聚在一起 所以一定要理解后再开始。

# 【UE5.3 PCG教程】PCG中的样条线和演员标签修剪森林道路生成

## 知识目标

- 用样条线和 Actor Tag 找到道路范围，并修剪森林或植被点，形成道路穿过森林的留白区域。

## 可复现主流程

- 给道路样条或道路 Actor 设置稳定标签，供 PCG 查找。
- 用 Get Actor Data/Get Spline Data 读取样条数据。
- 把森林点和道路样条距离做比较，过滤掉距离道路过近的点。
- 保留道路外侧点继续生成树木、草或环境实例。

## 复现检查清单

- 道路宽度应转成距离阈值或 Bounds。
- 样条采样精度太低会导致道路边缘出现漏删点。
- 复现时先固定随机种子，再调整密度、过滤和生成资源，避免随机结果掩盖逻辑错误。

# 编辑器资产与内容体系

## 覆盖范围

- Content Browser、Package Path、Object Path、Asset Registry。
- 资产保存、重命名、移动、删除、重定向器。
- 引用关系、软引用、硬引用、路径字符串引用。
- 导入导出、迁移、Derived Data、Asset Editor 状态。

## 阅读时机

- 需要定位资产、判断引用、清理资源、保存或删除资产。
- 任务涉及 `/Game/...` 路径、`.uasset` 文件、Asset Registry 或内容浏览器行为。
- 需要区分资产的载入、修改、保存状态与内容浏览器中的显示。

## 导入工作集与成果保留

高细节内容在导入准备期间耗尽内存，不直接证明最终场景必须降低细节。一次处理的源数据、转换中间结果和待载入对象构成制作时的工作集，与最终资产的运行预算是两个问题。先定位占用增长和失败发生的阶段，再比较缩小处理范围、释放中间结果或调整最终内容；只缩小批量也不保证累计占用会释放。

源数据生成、导入与派生数据准备、场景实例载入、资产保存可能是不同状态，某阶段的完成数量不能代替后续结果。分批推进还涉及输出身份：追加、覆盖或重建可能影响前批成果，不能只确认新批出现。若用保存后重开来释放累积占用，需要有可恢复的已保存成果；完成导入也不证明目标环境的运行内存、流送和帧耗时已经满足要求。具体状态与保留行为取当前导入工具，不将某个工具的批量或 Cook/Bake 按钮语义泛化为 UE 通则。

# Wevr Virtual Studio集成

> 路径：虚幻引擎5.7文档 / 建立你的开发流程 / 虚幻引擎中的协作和版本控制 / Wevr Virtual Studio集成

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/wevr-virtual-studio-integration-in-unreal-engine

[Wevr Virtual Studio（WVS）](https://about.wvs.io/)是一个云平台，面向使用虚幻引擎的团队，可提供远程团队协作和开箱即用的自动化服务，包括编译、渲染和测试。

WVS通过以下方式与虚幻引擎集成：

- 插件

  ：可在虚幻引擎编辑器中访问WVS基于Git的版本控制。
- 流程

  ：可帮助你自动在云端执行虚幻项目中常见任务的自动化单元，例如创建和部署版本、渲染美术和转换数据。

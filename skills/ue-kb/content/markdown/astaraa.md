### 概述

这是我的[构建工具](https://tinyurl.com/uemarket) 资产的指南，这是一组模块化/程序化工具，有助于在关卡设计和资产创建方面节省大量时间。它们都利用实例网格来提高性能。它们如下... 1. **Repeater** - 这是有史以来最有用的工具之一！ 2. **Wrapper** - 圆形和螺旋形的中继器。 3. **杂乱** - 物理产生的杂乱和成堆的东西。 4. **距离** - 获得尺度感。在区域内分散障碍物。 5. **高度工具** - 了解真实世界的高度。 6. **金字塔地板工具** - 以金字塔方向创建地板。 7. **大空心盒子** - 一个区域中的盒子。

### 中继器

![楼梯、栏杆、装饰、柱子](assets/unreal-engine-fab-astaraa-s-building-tools-guide/image-01.jpg)

![尝试创造有趣的图案。](assets/unreal-engine-fab-astaraa-s-building-tools-guide/image-02.jpg)

![对各种元素（例如走道）以及走道、柱子、楼梯上的随机边缘细节使用中继器。空心盒子用于框出区域并控制照明。](assets/unreal-engine-fab-astaraa-s-building-tools-guide/image-03.jpg)

中继器非常适合任何重复的东西；栏杆、楼梯、装饰、柱子、地板、天花板、塔、一堆书、走廊、墙壁*。*它可以在 X 和 Y 方向重复。我不需要同时了解所有 3 个方向。 （如果您这样做，请告诉我。） **不使用中继器的示例：例如，柱子**通常有 3 个网格：底部、中间和顶部。通常我们会将中间的堆叠到正确的高度，也许还会将它们分组。他们不会从实例中受益。然后，如果我们想让它们更高，我们必须解锁组，移动顶部并进行更多堆叠，如果它们的大小不适合网格并且我们要重新缩放，这会变得更加复杂。我们必须对房间里的“每根”柱子都这样做。最终不打扰，因为谁愿意做这一切。这是技术细节阻碍创造力的一个很好的例子。 **与使用它相比：** 作为中继器，我们改变了号码。完毕。我们可以一次选择所有这些并一次性更改数字。我们可以扩展它们。每件作品的所有定位都由我们处理。而且，他们从实例中受益。 **楼梯**特别有用，因为零件的尺寸通常不适合网格，并且它们是对角线的。设置起来很繁琐。更要做出调整。这个工具可以处理所有这些。 **选项：** 宽度 - 横向总重复次数。深度 - 向前的总重复次数。对于栅栏之类的物品，可以将其视为长度，而宽度会创建额外的栏杆。网格大小 - 我们需要设置的主要内容决定了重复之间的间距。变体 *（目前未使用）* 网格材质偏移反向 - 在相反方向重复。无需旋转。高度尺寸 - 如果 > 0 则高度增量。缩放 - 缩放网格，而不是整个 actor；而不影响其他偏移量。旋转增量比例 - 增加每个实例的比例。尺寸增大或缩小的东西。增加偏移量 - 每次增加偏移量这么多。示例：楼梯每次都会进一步向下或向上。增量旋转 - 相同，但旋转。增量偏移 X2 - 通过再次相乘将增量偏移变成更多曲线。无碰撞 WidthOffset - 仅向宽度/X 添加附加偏移。 **Caps** 端盖 - 在末尾添加一些东西。端盖网格 端盖变换 端部旋转跟随 - 跟随*旋转*变量。这可以在轴旋转不起作用的情况下有所帮助（可能是当网格横向移动（沿 X 轴）时）。 Start Cap - 在开头添加一些内容。起始帽网格 起始帽变换 **随机化** 随机化（函数）- 基于最小值和最大值生成随机变换。 RandomTransforms RandomMin RandomMax 具有不同前轴的网格物体仍然可以使用。尝试旋转（变量，而不是演员旋转）。 **向上：** 要使柱子向上重复，我们可以将 InstancedMesh 组件的 Rotation（我的意思是选择它并设置其旋转；而不是变量）设置为 X=-90，并将旋转变量 X 值设置为 90。然后 Depth 将使其向上重复，而不是向前。还将 *End Cap Transform* 旋转设置为 X=-90。示例已包括在内。

### 包装纸

![教程图片](assets/unreal-engine-fab-astaraa-s-building-tools-guide/image-04.jpg)

类似于中继器，但用于绕成一个圆圈。您可以用它做很多事情。您可以制作螺旋楼梯或走道，添加围绕对象的重复元素，制作圆形墙壁，填充圆形或甜甜圈形状的地板。任何圆形的东西，而中继器则用于直线。真正很棒的一件事是，当您可能还不知道自己在做什么时，您可以进行各种程序调整。所以你可以直接进去开始创作。

### 混乱的

![教程图片](assets/unreal-engine-fab-astaraa-s-building-tools-guide/image-05.jpg)

想制作一堆头骨吗？这就是我想要的。或者基于物理（它如何掉落并降落在地面上）的区域周围的杂乱？截至撰写本文时，这是新的和实验性的。我还没有进行重大测试，但到目前为止似乎没有产生负面影响。理论上它应该比单个网格表现得更好，并且不会创建大文件。从技术上讲，您可以与一堆元素进行交互，例如，如果需要，可以删除游戏中的单个元素。 （命中结果包括一个项目索引，指示哪个实例被命中。）当数量达到数千时，生成（模拟物理）确实会变慢（在模拟期间，它们使用非实例网格），但一旦生成完成的堆（实例）在空关卡中根本不会影响我的帧速率。选择大约 200+ 左右的数字确实感觉缓慢，但我再次没有注意到对帧速率的影响。我将继续在我自己的关卡设计中对此进行测试。在上图中，头骨是纳米粒子，而曼尼头骨不是。我也没有测试过这一点，但值得考虑。在我看来，nanite 的缺点之一是，虽然我们现在可以使用具有数百万个多边形的网格，但复杂的网格会带来很大的文件大小。但由于它们基于一个简单的网格 (134kb)，因此它们的文件大小很小。它由 2 部分组成，因为施工的运行方式，也为了不使 (1) 生成器与 (2) 桩/成品演员混淆或复杂化。使用这个工具，每个头骨都是一个实例 - 类似于树叶。另一种选择……不太好。我们会制作一堆，将其合并为一个网格。该网格将具有显着的文件大小和大量多边形。如果要重做的话也比较麻烦。例如，如果它们是网格： 288 个头骨：25mb，450k 个三角形 1,728 个头骨：330mb，270 万个三角形 **选项：** 网格 TotalX/Y/Z - 每个方向填充的元素数量。空间 - 设置此项，以便没有重叠。变换元素 - 告诉我们有多少个元素。 （警告：太多可能会开始运行得很慢。对我来说，1000+ 是可行的，但模拟起来明显很费力。） **使用：** 1. 添加 **B_ClutterGenerator** 并设置选项。 2. 确保间距足够，没有重叠。 [现在保存您的工作，以防万一。 💾]3.模拟关卡。 4. 选择演员后，单击“**开始**”。物品会掉落。 （注意：网格体必须具有简单的碰撞才能使物理原理发挥作用。还要确保碰撞实际上适合网格体，因为结果将与碰撞匹配。） 5. 等待元素完成下落（或者如果您希望它们在空中，请按暂停键？）。 6. 如果对结果满意，请单击 **CopyTransforms**。否则单击开始再次运行。 7. 然后应填充 Transforms 变量。复制该字段。 8. 停止模拟。 9. 添加 **B_ClutterPile**。 10. 将复制的变换粘贴到其变换字段中。结果应该是可见的。 11. 或者，如果它是在非平坦表面上生成的并且需要精确位置：复制 B_ClutterGenerator 的位置并将其粘贴到 B_ClutterPile，以便它们与模拟的精确位置匹配。请记住在移动发电机之前执行此操作。最后，您可能还希望创建 **B_ClutterPile** 的子级并将转换复制到子级中，以便可以重用它。否则它们只是关卡中的实例。

### 距离工具

![教程图片](assets/unreal-engine-fab-astaraa-s-building-tools-guide/image-06.jpg)

这主要是为了获得**距离感和尺度感**。但也可用于在一个区域中分散物体。可以每隔 X 米或 X 公里在水平面上放置一根柱子，然后快速查看 8 公里实际有多远。测量巨大的距离是最初的目标。或者添加随机性，使其更像是**分散工具** - 在大面积内随机大小和间隔的障碍物，无论是最终产品还是具有障碍物或覆盖物的原型。物体之间的距离应该有多远才能获得正确的感觉。它们是否太近、太远、太多？另一个用途是将**字符比例**网格放置在整个区域中，以便在环境中构建时始终具有角色大小的比例感。有一些选项可以切换杆、人物图形和文本。

### 高度工具

让您了解物体的高度（以米或英尺为单位）。最初，我正在雕刻一座塔，并有一个参考图像，其中包括某些点的高度（以英尺为单位）。这个工具让我可以看到引擎中 X 英尺的高度。提示：要获得 5'8，请在字段中输入 8/12，然后按 Enter 键以使用 UE 的内置计算器。然后像这样使用：5.6667

### 金字塔地板工具

将地板放置为金字塔形状。这有一个非常具体的用途，但它已经在项目中，所以我决定将其包括在内。我相信最初的目的后来被使用[Square Builder](https://tinyurl.com/uemarket)代替。

### 大空心盒

一个简单的节省时间的方法。有时我们想将一个区域包围在一个盒子中。与其他方法相比，这提供了多种便利。 1. 删除{墙名称} - 切换我们可能想要添加自定义入口/出口的任何墙。 2. DistanceFieldLighting - 切换光线是完全熄灭还是部分光线透过。 *（应该重命名，因为它会切换“影响”距离场照明，从而阻挡外部照明。请暂时忽略这个向后的名称。PitchBlack 会是一个更好的名称，因为这就是它的作用。）* 3. 厚度 - 调整所有墙壁的厚度。 4.材质/材质下限/材质上限-设置材质。地板和天花板有一个附加选项，因此我们可以轻松地使用黑色不发光材料设置底部。由于 SetAffectDistanceFieldLighting 在 UE 5.0 中不是可用节点，因此您需要在其他版本中自行添加此节点（见下图）。在 5.0 中，您仍然可以通过选择每个框的网格组件并在其选项中切换它来更改 AffectDistanceFieldLighting。它只是在 5.0 中不作为节点存在。

![添加 SetAffectDistanceFieldLighting 节点。](assets/unreal-engine-fab-astaraa-s-building-tools-guide/image-07.jpg)

### 转换为网格

假设您有一个用中继器制成的梯子，并且您想将其转换为常规静态网格物体。这可以通过建模工具使用 **Convert** 和 **Merge** 来完成，这会将 actor 转换为单独的网格，然后将它们合并。 （请记住事先检查您的源网格是否具有适当的简单碰撞。） - [Astaraa Assets](https://tinyurl.com/uemarket)

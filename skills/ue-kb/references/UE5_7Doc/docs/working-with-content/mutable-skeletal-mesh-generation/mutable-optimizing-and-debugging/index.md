# Mutable优化和调试

> 路径：虚幻引擎5.7文档 / 管理内容 / Mutable骨骼网格体生成 / Mutable优化和调试

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/mutable-optimizing-and-debugging-in-unreal-engine

**Mutable** 是一个面向虚幻引擎的工具集，用于在编辑器中或在运行时生成动态骨骼网格体、材质和纹理。它旨在帮助美术师和设计人员创建角色自定义系统，但也可以生成各种动态内容，例如动物、道具以及其他骨骼网格体资产。

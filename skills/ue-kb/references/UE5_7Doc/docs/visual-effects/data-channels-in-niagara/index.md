# Niagara数据通道

> 路径：虚幻引擎5.7文档 / 创建视觉效果 / Niagara数据通道

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/data-channels-in-niagara-for-unreal-engine

**Niagara数据通道（NDC）** 可实现游戏代码和Niagara系统间的通信，或是不同Niagara系统间的通信。Niagara数据通道可以将Niagara系统合并入一个大型共享模拟，从而实现对其的优化。

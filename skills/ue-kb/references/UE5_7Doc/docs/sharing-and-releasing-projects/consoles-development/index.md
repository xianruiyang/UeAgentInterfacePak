# 主机开发

> 路径：虚幻引擎5.7文档 / 分享和发布项目 / 主机开发

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/consoles-development-in-unreal-engine

虚幻引擎支持为所有主流游戏主机开发游戏。要开始开发，请参阅对应的主机页面并按照指示注册开发者身份并进行设置。

- [任天堂Switch](development-for-nintendo-switch/index.md) - 开始在虚幻引擎中为任天堂Switch开发游戏。

- [PlayStation 4](development-for-playstation-4/index.md) - 开始在虚幻引擎中为索尼PlayStation 4开发游戏。

- [PlayStation 5](development-for-playstation-5/index.md) - 开始在虚幻引擎中为索尼PlayStation 5开发游戏。

- [Xbox](xbox-development/index.md) - 在虚幻引擎中为Xbox开发游戏

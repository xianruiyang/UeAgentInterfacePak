## 中文整理

### 先决条件

以下是使用支持的 GPU 和 Matrox ST 2110 网卡集成 SMPTE 2110 的硬件和许可要求。

### 支持的 Matrox DSX 卡

支持的 Matrox SMPTE ST 2110 卡如下： - [Matrox DSX LE6 D100](https://video.matrox.com/en/products/broadcast-media/st2110-nic-cards/dsx-le6-d100) - [Matrox X.mio5 Q25](https://video.matrox.com/en/products/broadcast-media/st2110-nic-cards/xmio5-q25) - [Matrox X.mio5 D25](https://video.matrox.com/en/products/broadcast-media/st2110-nic-cards/xmio5-d25)** - [Matrox DSX LE5 Q25](https://video.matrox.com/en/products/broadcast-media/st2110-nic-cards/dsx-le5-q25) - [Matrox DSX LE5 D25](https://video.matrox.com/en/products/broadcast-media/st2110-nic-cards/dsx-le5-d25) - [Matrox DSX LE5 D25 LP](https://video.matrox.com/en/products/broadcast-media/st2110-nic-cards/dsx-le5-lp-d25)**

### 软件

要将 Matrox ST 2110 网卡与 Unreal Engine 一起使用，建议您遵循 Matrox ST 2110 网卡的 Matrox 安装和配置指南以及 *Matrox ST 2110 NIC 卡的 Matrox Unreal Engine 插件安装和用户指南*。 **注意：** 要获取有关 Matrox 如何为 Unreal Engine 提供 SMPTE ST 2110 专业视频 I/O 的信息，请使用 [Matrox Unreal Engine 插件联系表](https://go.matrox.com/en-forms-products-unreal-engine-plugin.html)。

### 00:03:42-00:08:28 Color、粒子、生命周期

- 本段定位：Color、粒子、生命周期。
- 知识点：而且还有一些大的缘 感觉填充空间的这种感觉适当减少 这种部分 需要加入一种 能够适当缓解的元素 像烟雾一样消失的 因为如果只用这个点 满满所有空间的话。
- 知识点：因为负载太重 混合这种粒子是优化 非常赚钱 只做大约十个 这个大约要抓住二秒的使用 需要先复制这个粒子。
- 知识点：纹理将使用序列纹理 所以流体的感觉 需要使用适当更多这种感觉 这个感觉更像是 烟雾般飘散而去 有消失的感觉 也要检查透明度 距离给100左右。

- 知识点：总之需要一些相机天意 感觉要把身体包裹成 角色 尺寸 变大时有烟雾的感觉 这个尺寸是120 100左右 生命周期是1-1.5秒左右。
- 复现要点：Initialize Particle 通常负责 Lifetime、Color、Position、Sprite Size 或 Mesh Scale 等基础属性。

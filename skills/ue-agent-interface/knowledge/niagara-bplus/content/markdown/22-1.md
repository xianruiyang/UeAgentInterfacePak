下方还能看到另外三组空的 `Dynamic Parameter` 区块，它们的 `Write Parameter Index` 都未启用，说明当前真正参与写入的只有最上面这一组四通道参数。

这张补充图的作用，是把 `S03` 阶段“贴图材质需要哪些动态通道”这件事说清楚：`Empty001` 在 `Particle Update` 里专门挂了一个 `Dynamic Material Parameters` 模块，并把滚动透明度、扭曲强度、颜色强度等控制项集中写到同一组参数槽中，后续材质实例就可以从这一组通道里读取粒子生命周期驱动出来的值。

## 复现检查

- 先单独验证 Emitter 的 Spawn、Lifetime、Renderer 和材质，再叠加到完整 Niagara System。
- 节点名、模块名和参数值以关键截图中的实际 UI 为准；OCR 只用于辅助定位。
- 涉及透明、Additive、SubUV、Flipbook 或 Depth Fade 时，重点检查材质混合模式、Alpha/Opacity 与 Emissive 强度。

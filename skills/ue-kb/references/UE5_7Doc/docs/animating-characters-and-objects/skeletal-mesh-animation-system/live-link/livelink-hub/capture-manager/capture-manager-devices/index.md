# 捕获管理器设备

> 路径：虚幻引擎5.7文档 / 为角色和对象制作动画 / 骨架网格体动画系统 / Live Link / LiveLink Hub / 捕获管理器 / 捕获管理器设备

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/capture-manager-devices

**捕获管理器**提供多种设备来决定如何摄取镜头试拍，包括**单目视频**、**立体视频**、**Live Link Face**和**镜头试拍档案**等。 你需要针对捕获的数据使用正确的设备。

- [单目视频设备](mono-video-device/index.md) - 概述捕获管理器提供的单目视频设备。
- [Live Link面部设备](live-link-face-device/index.md) - 概述捕获管理器提供的Live Link Face设备。
- [镜头试拍档案设备](take-archive-device/index.md) - 概述捕获管理器提供的镜头试拍档案设备。
- [立体视频设备](stereo-video-device/index.md) - 概述捕获管理器提供的立体视频设备。

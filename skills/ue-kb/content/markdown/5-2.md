### 用户工具箱概述

### 什么是用户工具箱？

用户工具箱是一个插件，允许用户创建一个充满不同命令的面板。这样他们就可以通过将所有最常用的命令放在同一个位置来自定义虚幻引擎编辑器。它是为分散在引擎内不同位置的具有特定需求的用户而设计的。显示 UTB 选项卡的方式有以下三种： - 在新面板窗口中（您可以从 windows>Usertoolbox>yourusertoolbox 打开它 - 在视口中作为侧面菜单（要刷新视口，您可以使用控制台命令中的 UserToolbox.LevelViewportOverlay 命令） - 在抽屉中（您可以使用控制台命令 UserToolbox.RefreshDrawer 来刷新它）

![教程图片](assets/unreal-engine-user-toolbox-5-2/image-01.jpg)

插件中已经内置了一些有用的命令，但用户也可以使用 BP 或 C++ 创建自己的命令，并自定义命令按钮的 UI 以适应命令用途。

### 如何启用它？

自 5.2 起，用户工具箱作为两个插件位于引擎内部： - UserToolboxBasicCommand（包含默认命令） - UserToolboxCode（包含框架）

![教程图片](assets/unreal-engine-user-toolbox-5-2/image-02.jpg)

### 它是如何运作的？

安装并激活插件后，您将需要通过在内容浏览器中右键单击来创建一个新的“选项卡”

![教程图片](assets/unreal-engine-user-toolbox-5-2/image-03.jpg)

创建选项卡后，它应该出现在 Windows/UserToolbox 的菜单中：

![教程图片](assets/unreal-engine-user-toolbox-5-2/image-04.jpg)

现在，您可以通过双击内容浏览器中的选项卡资源来打开选项卡编辑器，或者如果选项卡已打开，则可以通过单击选项卡右上角的钥匙图标来打开选项卡编辑器。

### 选项卡编辑器

![教程图片](assets/unreal-engine-user-toolbox-5-2/image-05.jpg)

选项卡编辑器将包含构建自定义工具箱的所有内容。简而言之，它将具有选项卡本身的属性，即您在其中设置命令的部分。

### 选项卡详细信息

- Name: The name of the tab - Active: An active tab will appear in the menu window>UserToolbox - Column Count: This property is used for tab UI customization - Tab UI: The list of custom tab UI Available.默认情况下，您有 1 个原始 UI 和 4 个基于编辑器工具栏的其他 UI - 默认命令 UI 覆盖：此属性允许您更改此选项卡中显示的每个命令的默认 UI。注意：如果在命令详细信息中指定了命令 UI，它将覆盖此参数中设置的 UI

### 选项卡部分

该面板管理选项卡的部分，您可以创建、删除和重命名部分。 “隐藏”部分是一个特殊部分，您可以在其中放置不应在选项卡中可见但可供其他命令（例如复合和切换命令）使用的命令。

### 命令列表

该面板显示所有可用命令的列表。可以使用蓝图或 C++ 代码创建命令。如果启用了“UserToolboxBasicCommand”插件，则会显示一组命令。

### 当前部分面板

这是当前部分内的命令列表。它们有自己的属性值（您可以在命令详细信息面板中设置它们） 要在部分中添加新命令，请将其从命令列表面板拖动到当前部分面板中。

![教程图片](assets/unreal-engine-user-toolbox-5-2/image-06.jpg)

通过右键单击此面板中的命令，您将能够将此命令复制/复制到另一个选项卡/部分中

![教程图片](assets/unreal-engine-user-toolbox-5-2/image-07.jpg)

### 命令详细信息

一旦命令位于某个部分中，选择它后，可以通过设置参数等来自定义该命令的特定实例...

![教程图片](assets/unreal-engine-user-toolbox-5-2/image-08.jpg)

一些命令属性对于任何命令都是通用的，例如： - 名称：命令显示的名称 - 图标路径：附加到该命令的图标，只有由图标跟踪器机制注册的图标可用。 - 工具提示：命令的工具提示 - 显示参数：如果选中，用户将可以在通过选项卡执行命令之前更改命令的属性 - 格式：这是 UI 的提示 - 键盘快捷键：您可以为此命令设置快捷方式 - UI 覆盖：您可以在此处更改命令的 UI。其他属性取决于命令的类型，例如，控制台命令将具有包含要执行的控制台命令的属性。注意：“显示参数”选项非常有用，因为它允许您在每次执行命令时更改命令属性。一个例子是按尺寸选择演员的命令。您无需为每个所需的尺寸创建命令，只需选中“显示参数”，每次单击该命令时，系统都会提示您设置所需的尺寸。当与内置的“按过滤器选择演员”命令一起使用时，这会变得更加强大，该命令允许您使用不同的过滤器组合来选择演员。

### 创建一个新命令

如果您想实现自己的命令，可以通过两种方式实现：

### 有了蓝图

通过右键单击内容浏览器，在 UserToolbox 菜单中，您将能够创建命令蓝图：

![教程图片](assets/unreal-engine-user-toolbox-5-2/image-09.jpg)

在蓝图编辑器中，您需要： - 编辑类默认值，设置命令名称等... - 通过实现命令事件来实现命令

![教程图片](assets/unreal-engine-user-toolbox-5-2/image-10.jpg)

### 使用C++

要在 C++ 中创建新命令，您需要子类化 /script/usertoolboxcore.UUTBBaseCommand 类。要实现该命令，请重写函数 UUTBBaseCommand::Execute() 这就是实现新命令并使其出现在命令列表中所要做的全部工作。如果您想在选中“ShowParameters”时自定义命令执行时的提示，您还可以重写函数 UUTBBaseCommand::DisplayParameters。

### 如何添加图标

为了简化为命令添加新图标的过程，我们实现了一个名为“IconTracker”的新资源，您可以通过在内容浏览器中右键单击来创建该资源。在此资源中，您将能够添加图标文件夹的路径并指定该文件夹中图标的大小。该文件夹中的每个图标都会根据文件名创建一个图标 ID。为了避免重复 ID，您可以为每个文件夹或每个 IconTracker 资源添加一个前缀，添加到图标名称中以生成 ID。对于每个 Icontracker，Usertoolbox 子系统将扫描文件夹并使图标在命令详细信息面板中可用。另外，如果您想在 UMG 中使用图标（例如，使用命令自定义 UI），您可以访问图标画笔：

### 如何自定义命令 UI

要自定义命令 UI，您需要创建一个 UMG 小部件并将其重新设置为 UTBCommandUMGUI。重新设置小部件的父级将允许您访问“获取命令”和“执行命令”节点。要将自定义 UI 的使用限制为特定命令集，您可以覆盖函数“Does support Class”来过滤命令类。

### 如何自定义选项卡

要自定义选项卡 UI，请对 UUTBDefaultUITemplate 类进行子类化并实现以下功能：

```cpp
TSharedPtr BuildTabUI(UUserToolBoxBaseTab* Tab);
```

和

```cpp
TSharedPtr BuildCommandUI(UUTBBaseCommand* Command, IUTBUICommand* ui);
```

您可以查看 4 个默认实现。

### 一些内置命令

### 复合命令

目前有两种复合命令，“复合命令”和“切换命令”，复合命令的特殊性在于它们在属性中使用了其他命令。在这种情况下，所使用的命令也应该属于该选项卡，因此放置它们的好地方是“隐藏部分”。复合命令将在一次执行中顺序执行多个命令。每次执行该功能时，切换命令将交替执行一组命令。这两个命令都有一个“内联”版本，允许您将嵌入命令直接定义到函数的参数中。可以混合使用复合命令和切换命令来创建复杂命令。

### 控制台命令

这是最基本的命令，但也是一个强大的命令。它允许您在用户工具箱中执行控制台命令，因此您可以使用控制台命令执行的所有操作都可以通过用户工具箱完成

# 动画与 Control Rig

## 覆盖范围

- Skeleton、Skeletal Mesh、Animation Sequence、Montage、Blend Space。
- Control Rig、RigVM、FK/IK、Full Body IK、Retargeter。
- Sequencer 动画轨道、Control Rig key、骨骼空间与控制空间。

## 阅读时机

- 需要制作或修改动画资产、Control Rig、IK/Retarget 资产。
- 需要排查姿态不动、骨骼偏移、空间错用、关键帧无效或 Sequencer 读回不一致。
- 任务涉及骨骼、控制器、目标点、局部/组件/世界空间转换。

## 后续填充位置

- Skeleton 与 Skeletal Mesh 的职责边界。
- Control Rig 控制点和空间规则。
- IK/Retarget 验证方法。
- Sequence 动画读回与截图验证注意事项。

# Datasmith文件格式互操作指南

> 路径：虚幻引擎5.7文档 / 管理内容 / Datasmith / Datasmith文件格式互操作指南

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/datasmith-file-format-interop-guides-in-unreal-engine

Datasmith的目标之一是支持在建筑、工程、施工、制造等各个行业中使用得最广泛的行业标准3D设计文件格式。大多数情况下，Datasmith在处理所有受支持的文件格式时过程大同小异，产生的结果也相差不大，详见[Datasmith概述](../datasmith-plugins-overview/index.md)中所述。

但是，每个受支持的文件格式为导入过程带来了独特的挑战和机遇。下面列出的指南详细说明了每种不同的数据源特有的额外注意事项。

- [CAD文件格式](importing-cad-files-into-unreal-engine-using-datasmith/index.md) - 介绍在使用Datasmith从CAD文件导入内容时需要特别考虑的因素。

- [IFC文件](importing-ifc-files-into-unreal-engine-using-datasmith/index.md) - 介绍仅在使用Datasmith将IFC文件中的场景导入虚幻编辑器时才适用的特殊注意事项。

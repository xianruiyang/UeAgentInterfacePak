# 将物理材质分配到物理资产形体

> 路径：虚幻引擎5.7文档 / Gameplay系统 / 物理 / 物理材质 / 物理材质教程 / 将物理材质分配到物理资产形体

> 原始页面：https://dev.epicgames.com/documentation/unreal-engine/assign-a-physical-material-to-a-physics-asset-body-in-unreal-engine

如果特定 **物理形体（Physics Bodies）** 需要不同的 **物理材质**，你可以分别对它们进行调整。

1. 在 **内容侧滑菜单** 中双击物理资产，用 **物理资产编辑器** 打开物理资产。

   ![Double-click a Physics Asset in the Content Browser to open it in the Physics Asset Editor](../../../../../../assets/images/d3/d32f9b552097f318701ab0cfb1c3e9a49c399b52ffc6d526aa661a7d77853fc3.jpg)
2. 选择

   一个物理形体。
3. 在 **细节（Details）** 面板的 **物理（Physics）** 类别中，更改 **简单碰撞物理材质（Simple Collision Physical Material）**。

   ![Change the Simple Collision Physical Material](../../../../../../assets/images/c4/c499f2c9f25857e7eedc1069f9092cd444c6dcaa2841be9d446b03ef983c0c97.png)
4. **单击保存**

   ![Click Save](../../../../../../assets/images/30/306884fb502d2c1c1cc85ae98d0c22a510744253beeced9ae13f0c5a89009cdc.png)

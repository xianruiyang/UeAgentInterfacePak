### 8. 定制

**显示名称**** **更改节点的名称。 **CompactNodeTitle** 直接在节点上显示紧凑标题，替换节点标题栏。 **ReturnDisplayName** 更改返回值的输出引脚名称。 **工具提示** 该方法的作用的描述。

**显示、压缩、返回、工具提示：示例**

```cpp
UFUNCTION(BlueprintPure, meta=(DisplayName="Other Display Name"))
bool DisplayName();
UFUNCTION(BlueprintPure, meta=(CompactNodeTitle="Compact"))
bool CompactNodeTitle();
UFUNCTION(BlueprintPure, BlueprintImplementableEvent, meta=(ReturnDisplayName="Amount"))
bool ReturnDisplayName();
UFUNCTION(BlueprintPure, meta=(ToolTip="This function does awesome stuff."))
bool ToolTip();
```

**AdvancedDisplay** 定义哪些参数仅在展开的节点上可见。

**高级显示：示例**

```cpp
UFUNCTION(BlueprintPure, meta=(AdvancedDisplay="Input3, bDebug, Output2, Output3"))
void AdvancedDisplay(bool Input1, int32 Input2, bool& Output1, float& Output2,
	double& Output3, double Input3 = 4.2, bool bDebug = false);
UFUNCTION(BlueprintPure, meta=(AdvancedDisplay=3))
void AdvancedDisplay2(bool Input1, int32 Input2, bool& Output1, int32& Output2,
	float Input3 = 1.3f, bool bDebug = true);
```

**关键字** 搜索此功能时可以使用的一组关键字。

**关键词：示例**

```cpp
UFUNCTION(BlueprintPure, meta=(Keywords="Example,Search,42"))
bool Keywords();
```

![关键词：示例](assets/unreal-engine-custom-blueprint-nodes-exposing-c-to-blueprint-with-ufunction/image-02.jpg)

**类别** 指定在蓝图编辑工具中显示的函数的类别。 - 嵌套类别可以用 | 定义

**类别：示例**

```cpp
UFUNCTION(BlueprintPure, Category="MyCategory|MySubCategory")
bool Category();
```

![类别：示例](assets/unreal-engine-custom-blueprint-nodes-exposing-c-to-blueprint-with-ufunction/image-03.jpg)

**CallInEditor** 该函数可以在实例的详细信息面板之外使用。 - 仅适用于没有返回值且没有参数的方法

**CallInEditor：示例**

```cpp
UFUNCTION(BlueprintCallable, CallInEditor)
void CallInEditor();
```

![CallInEditor：示例](assets/unreal-engine-custom-blueprint-nodes-exposing-c-to-blueprint-with-ufunction/image-04.jpg)

**Exec** 该函数可以在游戏内作弊控制台内使用。 - 仅支持特定类别 - Pawn - 玩家控制器、输入 - 作弊管理器 - 游戏模式、实例、引擎 - HUD

**执行：示例**

```cpp
UFUNCTION(Exec)
void ExampleExec(int32 Amount, bool bDebug);
```

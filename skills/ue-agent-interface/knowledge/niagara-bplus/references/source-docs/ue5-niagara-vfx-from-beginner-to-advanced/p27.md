这张图的重点是把速度设置和可见结果直接对应起来：

- 在 `Particle Spawn` 中改 `Add Velocity`
- 给 `(0,0,50)` 这样的线性速度
- 粒子就会在出生瞬间获得朝本地 `Z` 方向的初速度
